> **목사님의 정의 (2026-10-29):** 스토리QT는 성경을 잘 분석했다는 사실을 보여 주는 곳이 아니다. 성경 저자가 독자로 하여금 무엇을 발견하게 하려는지 파악하고, 성도들이 그 발견의 과정을 자연스럽게 경험하도록 만드는 곳이다. 따라서 원고는 본문 관찰에서 출발하고, 도구와 문학적 구조는 그 뒤에 따른다. 연구자는 깊이 분석하되, 성도에게는 쉽고 흥미롭게 이야기를 들려준다.
>
> **최상위 명제:** 본문이 먼저이고, 도구는 그 본문을 읽는 데 봉사한다. 성경 저자가 독자에게 사건·발언·정보를 **어떤 순서로** 알려주어 **무엇을 기대하고 판단하게 만드는지** 파악한 뒤, 그 독서 경험을 초신자도 따라갈 수 있는 2–3분의 스토리로 다시 들려준다.

**저자 원고 취급:** 사용자 연구 PDF와 미공개 논증을 공개 GitHub 저장소나 사용자 화면에 원문 그대로 싣지 않는다. 카드에는 성경 본문으로 다시 확인한 관찰과 승인된 설명만 짧게 옮긴다. 독자에게 보여주는 성경의 직접 인용은 앱이 사용하는 **개역개정 본문과 문자 단위 대조**를 원칙으로 한다. 사용자 연구 원고의 자유 번역·사역·가설은 그대로 개역개정 인용처럼 쓰지 않는다.

## B. 스토리QT의 정체성: 무엇을 하며 무엇을 하지 않는가

CBSR 전체의 교육은 다음과 같이 분담한다.

| 영역 | 주된 역할 | 성도 경험 | 평가 질문 |
|---|---|---|---|
| 본문 | 정해진 범위를 직접 읽기 | 말씀을 만남 | 통독 범위와 장면의 경계를 제대로 읽었는가? |
| **스토리QT** | 읽은 본문의 **서술 전략과 흐름**을 가볍게 보여주기 | 이야기를 이해하고 뜻밖의 발견을 함 | “오늘 무슨 이야기였지?”와 “왜 이렇게 전했을까?”가 함께 남는가? |
| 묵상 노트 | 본문 관찰 → 하나님의 성품 → 성경 전체로 → 적용·기도 | 자신의 말로 응답함 | 앞서 읽은 말씀에서 실제로 도출되는가? |
| 도전 | 본문 근거를 직접 다시 찾아봄 | 확인하고 발견함 | 정답 뒤에 근거절을 다시 펼쳐볼 수 있는가? |

- 스토리QT는 **시험이나 퀴즈가 아니다.** 자동 넘김이라는 익숙한 SNS 스토리 경험을 기본으로 하되, 본문 확인은 누르면 열리는 선택 기능이다. ‘잠깐, 본문에서 확인하기’는 필요할 때 **하루 최대 한 번**, 정답·점수·강제 없이 사용한다.
- 스토리QT의 성공은 일곱 도구의 사용 개수나 카드 수로 평가하지 않는다. **처음 성경을 읽는 사람이 2–3분 뒤 그날의 줄거리와 핵심 전환을 자기 말로 설명할 수 있는가**가 우선이다.
- 전문어(교차대구, 담론 시간, 내포 독자 등)는 연구자 메모에 두고 카드에는 **장면·말·행동·변화**로 번역한다. 도구 이름을 먼저 알려주지 않는다.
- 사건 설명 없이 ‘이것이 반복입니다’, ‘이것은 인간의 죄가 아닙니다’, ‘하나님의 임재를 회복합니다’ 같은 **분석·해명 문장만 이어진 원고**는 부적합하다.
- 단, **모든 성경 본문에 플롯을 만들지 않는다.** 율법·시·지혜·계보·예언·서신·묵시는 각각 실제 문학적 배열과 논리 전개를 따라 보여준다.

## C. 저자 원고 11편에서 배워야 할 **실제 독해 원리**

### C1. '무슨 일이 있었는가'와 '왜 이렇게 들려주는가'를 분리한다

관찰의 시작은 본문 속 사건·행동·대화다. 그 뒤에 **사건을 제시한 순서, 삽입한 단락, 되풀이하는 장면, 늦게 알려주는 정보, 어떤 일에 길게 머무는가**를 확인한다. 연구자가 발견한 A–B–X–B′–A′ 구조를 먼저 사용자에게 강의하지 않는다. **그 구조 때문에 독서 경험이 어떻게 달라지는지**를 이야기로 보여준다.

- **창 37–50:** 38장을 ‘요셉 이야기의 이탈’로 취급하지 않는다. '야곱의 톨레돗'에서 요셉의 돌봄·관리와 유다의 설득·책임이 어떻게 전개되는지 추적한다.
- **대하 21–24:** 여호야다·요아스·스가랴와 성전을 둘러싼 사건을 보여준 뒤, 성전 밖의 처형과 성전 안의 죽음, 왕권·제사장 리더십의 변화가 갖는 의미를 살핀다.
- **역대상 1–9:** 계보는 줄거리의 장애물이 아니라 **누구를 길게 기록하고 어느 계열을 배열·강조하는가**를 전달하는 형식이다. 억지로 개인 주인공이 등장하는 극적 사건으로 만들지 않는다.

### C2. 독자의 지식과 인물의 지식을 별개로 추적한다

**독자가 이미 알고 있는 것 / 현재 장면의 인물이 알 수 있는 것 / 서술자가 아직 공개하지 않은 것**을 구분한다. 인물의 말이 성경에 기록되었다는 사실과 그 말의 진위는 다르다.

- **욥 1–2:** 독자는 천상회의를 먼저 읽는다. 욥과 친구들이 그 정보를 전달받았다고 본문은 말하지 않는다. 이어지는 논쟁은 이 정보 차이에 비추어 듣는다.
- **창 31:** 하나님이 직접 주신 말씀과 야곱이 아내들에게 설명한 내용, 라반의 변명을 구별한다.
- **단 2·7·8:** 새로운 환상이 추가될 때 독자는 앞서 만든 해석을 수정하도록 요청받을 수 있다. **처음 카드에서 후속 장의 정보를 앞당겨 정답처럼 공개하지 않는다.** 왕국들의 역사적 동일시는 논쟁적인 연구 결론으로 구분한다.

### C3. 반복에서는 ‘다시 나왔다’보다 ‘무엇이 달라졌나’를 본다

창 12↔20의 아내–누이 이야기, 욥 1↔2의 천상회의, 삼상 24↔26의 사울을 살려주는 장면, 출 32↔34의 산에서 내려오는 모세가 이에 해당한다. **같은 표현이나 사물이 반복된다는 사실**을 먼저 확인하고, **행위자·대상·반응·결말·서술자의 평가의 차이**를 함께 확인한다.

### C4. 침묵·공백·생략은 기대가 형성된 자리에서만 읽는다

저자가 무엇을 안 썼다는 이유만으로 모두 의도된 공백은 아니다. 이미 패턴이 확립되었거나 문맥상 필요한 답이 기대될 때, **빠진 정보가 독자의 이해에 어떤 효과를 만드는지** 질문한다. 본문 밖에서 인물의 심리나 사건을 꾸며 넣지 않는다.

- 욥기의 논쟁 패턴에서 기도·응답의 유무가 달라지는 자리
- 아케다에서 거듭된 동행, 이삭의 질문, 멈춰진 칼, 숫양의 발견
- 다니엘에서 당장 공개하지 않는 정체와 점차 확대되는 설명

### C5. 말의 방향·형식·서술 속도도 의미를 만든다

- 창 37장의 르우벤과 유다가 형제들에게 제안하는 방식과 그 결과를 비교한다. **명령형/청유형이라는 이름**을 강조하기보다, 누가 어떻게 말해 실제 결정을 바꾸었는지 보여준다.
- 욥 15–21장의 인물들은 앞 사람의 말을 인용하거나 바꾸어 말하며 상대를 반박한다. 발언을 각각 분리된 교리 강의로 설명하지 않고 **논쟁의 진행**으로 들려준다.
- 창 22:9–11의 빠르게 이어진 동작은 결정적인 순간을 눈앞에 펼친다. 욥기의 긴 논쟁·하나님의 반복된 반문도 **서술의 길이와 리듬**을 통해 독서 경험을 만든다.

### C6. 정경은 의미의 지평을 넓히지만, 오늘의 본문을 압도하지 않는다

창 12:1↔22:2, 창 21:14↔22:3, 같은 책의 반복, 신약이 명시적으로 다시 언급하는 본문 등 **근거가 드러나는 연결**을 우선한다. 같은 단어가 나온다는 이유만으로 직접적인 인용·예표·저자 의도를 단정하지 않는다. **같은 점과 달라진 점**을 함께 설명한다. 학계에서 경쟁하는 번역과 구조 가설은 별도 연구 메모에 보존한다.

## D. 승인된 일곱 읽기 도구 — **원고를 만든 뒤 붙이는 이름**

| 도구 | 연구자가 살펴볼 것 | 성도에게 보일 표현의 방향 |
|---|---|---|
| **장면** | 본문의 단위·시간·장소·등장인물·새 장면 진입 | “그때 …에서 무슨 일이 벌어졌을까요?” |
| **인물** | 인물의 말·행동·변화, 하나님이 직접 하신 일 | 인물의 선택과 그 다음 결과를 눈앞에 제시 |
| **화자** | 서술자·하나님·인물·인용·전언 구분 | 누구의 말인지 짧은 이름표로 구분 |
| **전환** | 갈등이 꺾이는 실제 사건·말·발견 | “그런데…” 이후 달라진 일 보여주기 |
| **반복** | 말·물건·전형 장면, 새로 추가되거나 빠진 부분 | 장면 두 개를 보고 차이를 알게 하기 |
| **공백** | 기대된 말·반응의 부재, 정보의 지연 | 본문이 알려준 사실과 남겨 둔 질문 구별 |
| **아이러니** | 독자는 알지만 인물은 모르는 정보, 말과 실제 결과의 차이 | 독자가 이미 알고 있는 사실을 환기 |

- 원고마다 일곱 도구를 전부 적용하지 않는다. **하루 0–2개가 자연스럽게 도드라질 수도 있다.** 독자의 카드에는 이름을 강제 삽입하지 않는다.
- '아침/밤/저녁'은 발견 후보이지 자동 상징이 아니다. 변화가 실제 본문에서 확인될 때만 반복·전환 설명에 포함한다.
- 격언을 ‘장면’으로 부르거나 모든 예언 본문을 ‘고발→심판→약속’으로 배열하지 않는다.
- 96일차(삼상 24–26장)는 **본문이 만드는 이야기의 긴장**이 먼저이고, 카드의 `echo`·`table`이 나중에 이를 정리한다는 모범이다. 하지만 비교카드가 반드시 마지막에 있어야 한다는 뜻은 아니다.

## E. 발언의 출처와 신뢰도: **네 층위는 유지하되 기계적으로 진위를 결정하지 않는다**

사용자가 승인한 네 층위를 **검토의 출발점**으로 보존한다.

| 층위 | 자료의 성격 | 집필 기준 |
|---|---|---|
| **1. 가장 높음** | 하나님의 직접 말씀, 서술자의 명시적 서술·평가 | 그 **발언·서술이 실제로 무엇을 확언하는지** 정확히 전달 |
| **2. 높음** | 인물의 속말, 서술자가 알려 주는 인물의 생각·동기 | **그 사람이 그렇게 생각한다는 사실**과 **생각의 내용이 실제로 참인지** 구분 |
| **3. 검증 필요** | 인물이 다른 사람에게 한 진술·약속·비난·변론 | 그 인물의 주장으로 표시, 주변 서술·행동·후속 결과와 대조 |
| **4. 더욱 신중** | 제삼자가 타인을 평가하거나 전한 말 | 전언이라는 출처를 드러내고, 직접 검증이 없으면 단정하지 않음 |

**필수 주의점**

1. **신뢰도 사다리는 ‘화자의 종류에 따라 진실/거짓을 자동 판정하는 표’가 아니다.** 같은 인물도 사실을 말할 수 있고, 과장·오해·속임을 말할 수 있다. 발언의 내용과 기능이 관건이다.
2. 서술자가 인물의 속마음을 알려 준 경우, **그 인물이 그런 생각을 했다는 사실**은 높은 신뢰도를 갖지만, 인물이 생각한 내용까지 저자가 진리로 승인한 것은 아니다(예: 삼상 27:12의 아기스의 생각).
3. **서술자가 발언을 인용했다는 사실과 발언 내용을 승인했다는 판단을 분리**한다. 하나님을 언급한 아비새(삼상 26:8)나 아론(출 32:24)의 말을 곧바로 하나님의 판정으로 바꾸지 않는다.
4. **인물 둘이 같은 말을 하거나 상대가 반박하지 않았다는 이유만으로 사실 확정하지 않는다.** 이런 것은 문맥에 따라 신빙성을 높일 수 있는 단서일 뿐이며, 둘이 공유하는 오해·이해관계나 침묵의 이유도 고려한다.
5. 반대로 ‘본문이 명시적으로 확정하지 않는다’고 해서 서사에서 이미 제공한 근거를 지우지 않는다. 사건 전후의 물증·행동·독자 정보·다른 본문의 확인을 종합한다. 최종 판단이 열려 있으면 그대로 열어 둔다.
6. 하나님·선지자·사도라는 **직함 자체로 매 순간의 모든 발언을 일괄 판정하지 않는다.** 직접 말씀의 전달인지, 개인 의견인지, 타인의 말 인용인지 구별한다.
7. 화면의 `q` 인용에는 가능한 한 **‘하나님의 말씀’, ‘○○의 말’, ‘본문의 설명’**처럼 출처를 표시한다. 이름표는 **누가 말했는지**를 표시하는 것이며 **그 인물의 말이 참이라는 인증마크는 아니다**.

연구자 검수 질문: `누가 무엇을 말했다/생각했다?` → `그 내용을 독자는 언제 알게 되었는가?` → `본문이 확인·반박·유보하는가?` → `원고는 이 확실성 수준을 지키는가?`

## F. 원고 제작 표준 절차 — **연구(비공개)와 카드(공개)를 분리**

### 0단계. 경계와 통독 범위 확인

2027년 A판의 그날 실제 범위를 확인한다. 앞날에서 이어지는 맥락과 다음 날로 남겨야 할 사건을 적는다. 장 제목이나 전통적 소제목을 곧바로 문학적 단락 경계로 확정하지 않는다. **3–5장 전체에 억지로 단일 플롯을 만들 필요는 없다**. 범위 안의 주요 단위들과 그 연결을 정직하게 제시한다.

### 1단계. 첫 번째 독서 — 절을 따라 있는 그대로 기록

분석 틀·플롯 유형·카드 JSON·그림 목록을 보지 않고 먼저 읽는다. 아래를 기록한다.

| 필드 | 기록 내용 |
|---|---|
| 본문 범위 | `책 장:절–절` |
| 누가·어디서·언제 | 명시된 인물·장소·시간 |
| 실제 행동과 발화 | 직접 언급된 행동, 발화자, 대상 |
| 직후의 결과 | 본문이 바로 알려준 결과 |
| 독자가 이미 아는 정보 | 이전 단락에서 먼저 제공된 정보 |
| 등장인물이 아는 정보 | 말·행동으로 확인되는 범위에 한정 |
| 확인하지 않은 것 | 본문에서 아직 미정인 동기·결과·정체 |

**금지:** 머릿속 추정으로 순서를 뒤집거나, 인물의 심리·대화·상징을 추가하지 않는다. 사물을 활용한 시각적 연출 역시 본문에 실제 등장하는 것만 사용한다.

### 2단계. 두 번째 독서 — 독자 경험의 변화를 추적

다음을 반드시 질문하지만, **모든 질문에 답을 채우지 않는다**.

- 이 장면 앞에서 독자는 **무엇을 기대하게 되는가**?
- 다음 사건으로 인해 **어떤 기대가 충족·좌절·수정**되는가?
- 누구의 말·행동이 실제로 사건을 바꾸는가?
- 반복되는 장면에서 **유지되는 것과 달라지는 것**은 무엇인가?
- 서술자는 **정보를 언제 공개하고 무엇을 아직 공개하지 않는가**?
- 길게 들려주는 대화/짧게 요약하는 사건의 **비중 차이**는 어떤 효과를 만드는가?
- 핵심 문제는 해당 날짜에서 **해결·부분 해결·미해결** 중 어디에 놓이는가?

이 단계가 저자 원고에서 특히 두드러지는 차별성이다. *다니엘의 점진적 환상 공개, 욥의 천상회의와 논쟁, 야곱과 라반의 전언, 아케다의 결정적 동작, 역대기의 인물·계보 배치*가 본보기다.

### 3단계. 본문 안에서 중심 질문 선택

먼저 2–3개의 경쟁 가능한 후보를 연구 메모에 적고, 그날 통독 범위의 중심 현상과 연결되는 **하나만** 선택한다. 가급적 `왜 / 무엇이 달라졌나 / 누가 사건을 돌렸나 / 독자는 언제 알게 되었나`의 형태를 사용하되 의문사 형식을 강요하지 않는다.

**선정 기준:** 본문 근거가 선명함, 앞뒤 카드의 결속을 만드는 힘, 초신자에게 설명 가능함, 마지막에 답하거나 미해결 상태를 명확히 밝힐 수 있음. 이미 계획표에 있는 축 구절·질문은 **참고 자료**이지 본문 관찰보다 먼저 결론을 결정하는 문구가 아니다. 충돌 시 기록 후 연구자 검토를 요청한다.

### 4단계. 먼저 ‘이야기만’ 6–10문장으로 작성

카드가 아닌 연속된 문장으로 `그때 → 그런데 → 그러자 → 다시 → 마침내` 등 자연스러운 흐름을 만들어 본다. 문장마다 **새 행동·발언·정보·결과**가 있어야 한다. 인물·시간의 연결을 알 수 없는 곳은 억지 접속사로 메우지 않는다. 율법·시·예언·서신에서는 사건 서술 대신 **규정·시적 움직임·예언의 청중과 응답·논증의 전개**로 같은 작업을 한다.

### 5단계. 문학적 구조는 **검증한 뒤 필요한 만큼만** 카드에 반영

표(`table`), 견주기(`echo`), 인용(`quote`)은 발견을 정리할 때만 사용한다. **대칭 구조를 찾았다는 이유만으로 카드의 중심을 정하지 않는다.** 짝 사이에 실제로 동등한 문학적 기능이 있는지 확인하고, 불확실하면 연구자 메모에 남긴다. 비교카드는 중간에도 올 수 있다. 카드 순서·수는 이야기의 호흡에 종속된다.

### 6단계. 사용자에게 보일 스토리 카드 작성

- **대상:** 초신자, 청년, 처음 통독하는 성도. 2–3분 내 읽기·시청 가능하도록 간결하게.
- **분량:** 보통 9–12장, 한 장 120자 안팎을 지향하며 200자 초과는 경고. 이것은 기술적 권장치이지 본문 내용을 제거할 이유가 아니다.
- **표지:** 장황한 교훈이 아니라 본문이 실제로 제기하는 궁금증. 해당 질문은 결말·생각거리에서 다시 다룬다.
- **몸통:** 가급적 한 카드 한 장면/한 움직임/한 논지. 새 사실이 없는 반복 해설은 합친다.
- **인용:** 필요 시 짧게, **본문 주소를 함께**. 인물 발언·본문의 설명을 구분. 직접 인용은 개역개정 원문과 일치시키고 생략은 `…`로 표시한다.
- **결말:** 무엇이 달라졌는지 보여준다. 본문이 미해결로 남겨둔 것은 ‘정답 없음’으로 덮지 말고 **본문이 확인한 것과 남긴 것**을 구분한다.
- **문학적 구조:** 가능한 경우 독자가 장면을 따라간 뒤 비로소 눈치채도록 구성한다. 도구 이름은 해설 카드의 제목처럼 강요하지 않는다.
- **영상 흐름:** 일반 설명 카드는 짧고 리듬 있게, 비교·본문 확인 카드는 충분한 시간이 주어지도록. 자동 넘김 설계는 Claude 담당.

### 7단계. 묵상 노트의 네 단계에 연결

`본문 관찰(obs)` → `하나님의 성품(god)` → `성경 전체로(christ)` → `적용·기도(apply, pray)`.

- `obs`: 스토리 본문에서 실제 관찰한 사실과 관련 절. 원고의 별개 주제로 바꾸지 않는다.
- `god`: 하나님이 **본문에서 하신 말·행동·판단·응답**을 근거로 쓴다. 신학적 일반론을 먼저 적지 않는다.
- `christ`: 본문에서 확인 가능한 성경 인용·사건 언급·문맥 있는 반복·자기 지시가 있을 때만. **없으면 비워도 된다.** 같은 점과 다른 점을 함께 확인한다. 직접적인 정경 관계와 연구자의 해석적 유비를 구별한다.
- `apply`: 장면의 신학에서 현실의 **하나의 구체적 질문**으로 연결한다. 인물을 무조건 본받거나, 질병·출산을 도덕적 죄로 바꾸거나, 본문의 폭력을 일반적 행동 지침으로 확대하지 않는다.
- `pray`: 앞선 관찰·성품·적용과 맞닿는 2–3문장. 같은 해명이나 추상적 권면을 반복하지 않는다.
- `kwq`: 표지 질문을 기계적으로 되풀이하지 않고, 오늘의 본문과 사용자 자신의 삶이 만나는 자리에서 **하나의 생각거리**를 만든다.

### 8단계. 제출 전 역검증과 최종 승인

**독해 점검:** 이름표·도구·해설을 가려도 하루의 이야기/논지 전개가 보이는가? 이야기 전체가 **하나의 중심 질문**에 기여하는가?

**서술 점검:** 사건의 배열·시제·정보 공개 시점·발언자·인물의 정보 수준이 왜곡되지 않았는가?

**문학 점검:** 반복의 **차이**, 공백이 만들어내는 **기대**, 서술의 **강조점**이 카드에서 정확히 기능하는가? 공통점을 만들기 위해 차이를 지우지 않았는가?

**신학 점검:** 인물의 판단을 하나님의 뜻으로 승격하지 않았는가? 정경 연결과 적용이 실제 근거에서 나오는가? 경쟁적 해석을 확정된 사실로 제시하지 않았는가?

**UX 점검:** 한 카드가 지나치게 설명적이지 않은가? 같은 해명이 두 번 이상 반복되지는 않는가? 2–3분 시청으로 핵심 사건을 회상할 수 있는가?

**승인:** 기계 검사가 JSON 구조·인용·주소를 통과해도 **문학적 타당성 승인과 성도 화면 검수는 별도**다. GPT 검토와 사용자의 판정을 거쳐야 최종 확정한다.

## G. 장르별 전개 원칙 — **정답 템플릿이 아니라 관찰 질문**

| 본문 종류 | 우선 볼 것 | 금지할 오류 | 카드에 자연스럽게 나타낼 것 |
|---|---|---|---|
| 역사·복음서 | 사건의 순서, 인물의 선택, 서술자 정보, 반전 | 모든 인물 심리 단정 | 실제 장면의 이동, 선택, 결과 |
| 율법 | 대상·조건·예외·동기절·삽입 일화 | 법규를 인물 갈등 플롯으로 억지 변환 | 규정이 바뀌는 조건과 공동체 목적 |
| 시·애가 | 병행, 발화자의 방향, 호소→신뢰 등 전환 | 무조건 탄식→찬양 도식 | 말하는 사람과 주목하는 대상의 변화 |
| 잠언·전도서 | 대구·격언의 긴장, 반복·예외 | 격언 하나를 보편적 무예외 법칙으로 고정 | 상충하는 잠언을 함께 읽을 때 생기는 질문 |
| 욥기 | 발화 차례, 실제 발언/재인용, 서술자·하나님 평가, 반복의 변주 | 친구·엘리후의 말 전체를 하나님의 직접 가르침처럼 제시 | 논쟁의 긴장, 독자가 가진 선행 정보 |
| 예언 | 화자·청중, 고발/심판/약속, 후렴·질문·환상 배열 | 모든 날을 고발→심판→약속에 맞춤 | 반복 공식의 실제 기능과 어긋남이 있다면 그 차이 |
| 서신 | 문제·주장·근거·반론·권면 | 특정 본문에서 없는 반론을 창작 | 논증의 흐름과 ‘그러므로’가 연결하는 내용 |
| 묵시 | 본 것/들은 것, 환상 순서, 반복·해석의 유예 | 논쟁적인 상징의 역사적 정체를 확정 사실처럼 공개 | 독자에게 정보가 새로 주어지는 순서 |
| 계보 | 배열·생략·강조·계열의 연결 | 극적 사건이 없다고 무의미한 이름 나열로 처리 | 누구에게 시선이 모이고 어떤 공동체가 형성되는가 |

`시 15–24편 교차대구`, `다니엘 네 왕국의 역사적 동일시`, `아케다의 경쟁적 해석`처럼 강한 연구 가설은 내부 메모에 남기고 원고에는 **직접 확인되는 대응과 변화를 설명하는 데 필요한 만큼만** 사용한다.

## H. 실제 사례: 모범·실패·수정 방향

### H1. 96일(삼상 24–26) — 모범의 원리

- 24장: 사울이 굴에 들어오고 다윗이 겉옷 자락을 벤다. 그러나 죽이지 않는다.
- 25장: 나발의 모욕을 듣자 다윗이 칼을 차라고 한다. 아비가일이 와서 멈춘다.
- 26장: 사울은 다시 다윗의 손이 미칠 자리에 있고, 창과 물병이 곁에 있다. 다윗은 다시 죽이지 않는다.
- **뒤에서** ‘다윗이 사울을 대할 때와 나발을 대할 때’의 차이, 누가 무엇을 말했는지와 하나님께 맡긴다는 판단을 정리한다.
- **배울 것은 카드 순서의 외형이 아니라** 사건이 비교의 필요성을 스스로 만들어낸다는 점이다.

### H2. 14일(창 37–39) — 단일 반복 소재로 축소하지 말 것

`옷·염소·알아봄`은 유익한 반복의 실마리다. **하지만 그것이 세 장 전체의 주인공이나 유일한 주제가 되어서는 안 된다.**

1. **37장**: 요셉을 향한 미움→시기→살해 모의로 갈등이 증폭된다. 르우벤·유다의 서로 다른 개입으로 사건이 바뀐다. 야곱은 피 묻은 옷을 보고 잘못된 결론을 내린다.
2. **38장**: 요셉 이야기가 잠시 멈추고 유다의 가정·자손 위기로 시선이 옮겨간다. 다말은 물건을 보내고, 유다는 자신의 행동을 인정한다(38:26). 37장에서 동생을 판 일을 모두 회개했다고 확대하지 않는다.
3. **39장**: 다시 요셉에게 돌아온다. 옷 때문에 무고당하지만 보디발의 집과 감옥에서 **여호와께서 요셉과 함께하심**과 일의 위탁이 반복된다.
4. **그 후** 세 장의 속임·물증·판단·인물의 선택 차이를 필요한 한 장에서 정리한다. 27장의 염소·옷은 배경 설명으로 제한한다.

### H3. 32일(출 32–34) — 개념 설명으로 장면을 대체하지 말 것

`언약 파기 → 임재 위기 → 갱신`이라는 분석은 유효하지만 그 문구를 매 카드에 반복하지 않는다. 금송아지를 만드는 손, 춤추는 진, 깨지는 돌판, 진 밖의 장막, 모세의 간구, 반석 틈, 새 돌판을 든 두 번째 하산, **모세의 빛나는 얼굴(34:29–35)**을 먼저 보여준다. 특히 **33:7은 반복적 관행을 소개하는 문장**이므로 금송아지 직후 새로 세운 회막으로 단정하지 않는다.

### H4. 38일(레 13–15) — 예방 설명이 이야기 전체를 점령하지 않게

의례적 부정이 도덕적 죄와 동일하지 않다는 경계는 반드시 필요하지만, 카드마다 반복하면 규정의 실제 목적이 가려진다. **필요한 한 곳과 적용 부분에서만** 분명히 하고, 나머지는 제사장의 진찰, 재검, 정결 절차, 성막과의 관계를 보여준다. 레 13:46↔14:3의 '진영 밖'은 **회복을 확인하기 위해 나가는 제사장**과 그곳에 머무는 사람의 방향 차이를 보여주되, 그 비교 자체가 자동으로 신학적 구원을 증명한다고 확대하지 않는다.

### H5. 아케다와 다니엘 — 의미를 먼저 공개하지 않는다

- **창 21–22**: 두 번의 아침이나 ‘하늘에서 부름’ 중 실제 전개에 가장 기여하는 하나를 고른다. 22:9–11의 빠른 동작과 멈춰선 칼, 숫양의 발견을 먼저 들려준다. 경쟁적 해석은 연구 자료에 보존한다.
- **단 2·7·8**: 각 환상을 본 시점의 정보만 먼저 제시한다. 후속 환상은 기존 이해를 복잡하게 만들 수 있다. 역사적 왕국 동일시와 장별 교차 구조는 확인된 범위만 사용하고, 모든 수수께끼를 오늘의 카드에서 풀어버리지 않는다.
- **욥기**: 천상회의의 정보는 먼저 독자에게 주어졌다. 이후 친구와 욥, 엘리후의 발언은 **서로를 인용·반박하는 실제 순서**로 들려준다. 어떤 해석이 타당한지는 하나님과 서술자의 평가, 본문의 진행과 구분하여 설명한다.

## I. 제작용 자료와 자동 검사 — Claude의 구현·운영 기준

### I1. 제출 산출물(변경 원고마다)

1. **근거 메모**(비공개): `날짜 / 범위 / 장면·논지 목록 / 독자 정보 / 인물 정보 / 중심 질문 후보 / 선택 이유 / 연구 가설과 확정 관찰 구분`.
2. **연속 이야기 뼈대**(비공개): 카드로 나누기 전 6–10문장. 비서사라면 논증·시적 구성의 흐름 메모.
3. **클로드가 받는 원고 JSON**: 기존 합의된 `replace_day`(전면 재작성) 또는 `replace_cards`·`insert_after`·`set`(부분 수정) 방식. **2027 A판만** 지정.
4. **인계 메모**: 핵심 변화, 빼기로 한 내용, 인용·화자·범위 검사 결과, 논쟁적 해석과 확인되지 않은 항목.

### I2. 자동화할 수 있는 검사

| 자동 검사 | 판정 방식 |
|---|---|
| JSON 키·카드 종류·필수 필드·카드 개수 | 명확한 오류는 차단 |
| 인용 문자·장절 존재·통독 범위 | 오류 차단 또는 외부 본문 경고 |
| 이름표 누락·본문에 화자 존재 가능성 | 이름표 후보 검토 요청 (자동 진실 판정 X) |
| 같은 해명·동의어 표현 반복 | **의미 중복 후보** 경고, 사람이 판단 |
| 표지 질문과 마지막 카드·QT의 주제 차이 | **응결성 후보** 경고, 사람이 판단 |
| 2027 A 외 변경, 원고 해시 변경 후 승인 유지 | 차단 또는 재검토 상태로 복귀 |
| 카드 길이·복잡한 문장·시청 시간 | 사용자 경험 검토 경고 |
| 외부 연구 PDF의 장문 복제 | 공개 저장소 반영 차단 |

### I3. 자동화하면 안 되는 판정

- `정관사 / 대명사 / 인칭 / 동사 형태`의 기계적 발견만으로 **저자 의도나 의미를 확정**하는 일
- 인물의 화자 층위만 보고 **진실·거짓을 판정**하는 일
- `아침`, `보라`, `그러므로`가 나타났다는 이유로 **전환·구조의 중심을 확정**하는 일
- 자동 추출된 반복 횟수만으로 **핵심 주도어·교차대구를 확정**하는 일
- 사람의 주해 승인 없이 **그리스도 예표·정경 연결·목회적 적용을 자동 생성**하는 일

**작업 상태:** `초안 → 구조·인용 검사 → GPT 본문/논지 검토 → 사용자 최종 승인 → 배포`. 승인 후 원고 내용이 변하면 다시 검토한다. Claude는 실제 앱에 반영하되, **원본 연구 파일이나 이전 승인본을 임의 폐기하지 않는다**.

## J. 단일 원고 최종 승인 체크리스트

> 모든 체크를 통과해야 Claude가 최종 승인 요청을 할 수 있다. 기술 검사만 통과한 원고는 **검수 완료가 아니다.**

- [ ] 오늘 2027 A판의 **실제 통독 범위**를 빠짐없이 고려했고, 이전·다음 날의 경계가 정확하다.
- [ ] 카드에서 **실제 사건·행동·발화·배열**이 분석·해석보다 먼저 보인다.
- [ ] 하나의 중심 질문이 전체를 이끌며, 마지막에 **답 또는 명시적 미해결**로 회수된다.
- [ ] **독자·인물·서술자**가 각각 가진 정보와 공개 시점을 혼동하지 않는다.
- [ ] 인물의 말과 본문이 확언한 사실을 **구분**했고, 독백의 내용까지 자동으로 참이라 하지 않았다.
- [ ] 반복/대조를 택했다면 **같은 점과 달라진 점**이 각각 절로 확인된다.
- [ ] 삽입 장면·계보·규정 등 주요 단위를 통독 범위에서 **편의상 지우지 않았다**.
- [ ] 공백·심리·인과관계·역사적 동일시 등은 **확실성 수준**을 지켜 표현한다.
- [ ] 별도로 유도한 신학적 결론·정경 연결·적용이 **실제 본문**에 기대고 있다.
- [ ] 같은 주의 문장이나 결론을 여러 카드에서 되풀이하지 않는다.
- [ ] 직접 인용은 앱 개역개정 본문과 일치하며 **절 번호와 화자 이름표**가 정확하다.
- [ ] 초신자가 2–3분 뒤 오늘 읽은 본문의 **흐름과 뜻밖의 발견 하나**를 말할 수 있다.
- [ ] JSON 자동 검사와 **사람의 내러티브·신학 검토**를 별도 수행했다.

## K. Claude에게 요청하는 처리 범위

1. 이 문서를 스토리QT의 **최상위 집필·편집 기준**으로 사용하되, 이미 승인된 일곱 화면 도구와 본문/QT/도전 역할 분담은 유지한다.
2. `CBSR_내러티브_원칙(3).md`의 연구용 분석 항목과 `CBSR_목사님원고_153성경읽기_활용.md`의 날짜별 메모는 **보조 검수 자료**로 유지한다. 이 문서를 근거로 기존 원고 전체를 기계적으로 일괄 재작성하지 않는다.
3. 향후 원고 작업 시 **본문 관찰표 → 정보/기대 변화 → 중심 질문 → 연속 이야기 → 카드 → QT 연결 → 자동 검사 → 연구자 승인** 순서를 지킨다.
4. 특히 **말의 신뢰도 층위는 검수 우선순위**이지 자동 진실 판정 공식이 아니라는 점을 명시한다. 다른 인물과의 일치·상대의 침묵도 자동 확증으로 처리하지 않는다.
5. 추후 날짜별 수정 JSON을 받으면 **최종 승인 전에는 기존 확정 원고를 덮어쓰지 않는다**. 2028년 B판과 통독 기록은 보존한다.
6. 배포 뒤에는 초신자 사용자 시험에서 `오늘 이야기는 무엇인가`, `새롭게 발견한 것은 무엇인가`, `어느 부분이 다시 궁금해졌는가`로 점검한다. 마지막 질문에 ‘없다’고 해도 실패가 아니다.
