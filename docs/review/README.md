# CBSR 원고 교정 — 사무실(CBAO)에서 이어 하기

(폴더와 파일 이름은 Windows 경로 문제를 피하려고 영문으로 둡니다. 예전 이름: docs/교정/12월체험판_원고_1.csv)

2026-11-26부터 원고 윤문·교정·검수는 사무실(https://aqedah.github.io/CBAO/#/office)의 CBSR 대화방에서 합니다. 이 폴더는 그 작업에 쓰는 원고 묶음과 결과를 둡니다.

- 칸 경로는 `trial26_qt.json`의 `qt.<날>.` 아래 경로입니다. 예: 330일 `obs.pair.0.1`은 `qt["330"]["obs"]["pair"][0][1]`입니다.

## 목사님이 이미 정하신 것 (맞대기 때 꼭 지킬 것)
- **목사님 문장은 고치지 않습니다.** 책머리 f0의 도구 풀이와 원고 CSV '표시' 열에 '목사님 문장'이 적힌 줄입니다. 의견만 냅니다.
- **'서술자'는 그대로 씁니다**(11-24). '본문'으로 바꾸지 않습니다.
- **문장 끝은 '-입니다/-습니다'로 맺습니다.** '-겁니다'는 여운이 필요한 곳에만 씁니다(11-13).
- **기도:** '-소서'로 맺고, 1인칭은 '제'로 씁니다. 장절은 넣지 않습니다. 끝은 "예수님의 이름으로 기도합니다. 아멘."입니다.
- **개역개정 인용은 글자 그대로 둡니다.** 대조는 `app/bible.b64`(gzip+base64 JSON, [권][장][절], 개역개정)로 합니다. 작업 폴더에 따로 있는 krv.json은 개역한글이라 쓰지 않습니다.
- **맞춤법 판정:**
  - '죽임당하다', '구원받다', '사랑받다'는 붙여 씁니다(접미사).
  - 지명 뒤 산·강·섬은 원고 문장에서 붙여 씁니다(시내산, 시온산, 밧모섬).
  - 이 세 가지에서 Gemini는 반대로 짚은 적이 있습니다.
- **짧은 칸:** '~지요', '우리', '-겁니다'를 넣지 않습니다. "~할까요?" 같은 물음은 허용합니다.

## 원고에 반영하는 법 (Claude, 고쳐 주기 모드)
1. 먼저 `git pull --rebase origin source`.
2. 고칠 곳은 `app/site_src/trial26_qt.json`의 그 날 칸에서 **원문 문자열을 정확히 찾아** 바꿉니다.
   - 같은 날 안에서 같은 문장이 `obs.pair`와 `v27.looks`, `note`와 `god`처럼 두 칸에 겹쳐 있으면 둘 다 바꿉니다.
   - 파일을 통째로 다시 쓰지 않습니다. 옛 사본으로 덮어써 다른 세션의 변경이 사라진 일이 있습니다.
3. JSON은 `json.dumps(…, ensure_ascii=False, indent=1)`로 저장합니다. 원래 꼴과 같습니다.
4. 같은 문장이 원고 원본(`guide27/trial_w*.json`, `trial_w*.py`, `trial_v3_content.py`)에 **한 번만** 있으면 그것도 같이 고칩니다. 그래야 `to_guide_qt.py`를 다시 돌려도 되돌아가지 않습니다. `.py`는 고친 뒤 `python -m py_compile`로 확인합니다(작은따옴표 겹침 주의).
5. 새로 넣은 큰따옴표 인용은 개역개정과 글자 대조합니다.
6. 커밋 작성자는 aqedah입니다. 커밋 메시지에 반영한 번호를 적습니다.
7. 결과는 이 폴더에 `trial12_applied_<날짜>.csv`로 남깁니다(번호, 원문, 고친 문장, 판정, 근거).
