**한 문서로 묶인 비(非)내러티브 원칙은 없습니다.** 특히 예언서는 원칙이 비어 있습니다. 그런데 3–10월 원고의 큰 몫이 예언서입니다(이사야–말라기 약 70일).

## 1. 내러티브비평에서 그대로 가져오는 것 (모든 장르 공통)

7가지 도구 가운데 아래는 장르와 상관없이 씁니다. 이름도 화면 이름 그대로 씁니다.

| 도구 | 비내러티브에서 무엇을 보나 |
|---|---|
| **반복** | 후렴, 공식 문구, 주도어. **같은 틀이 몇 번 도는지, 몇 번째에 무엇이 바뀌는지** |
| **대조** (반복 안에 둠) | 두 길, 두 여인, 두 성, 의인과 악인, 심판과 회복 |
| **생략** (공백을 넓힌 것) | 되풀이되는 틀에서 **빠진 칸**. 기대된 대답이 없는 자리 |
| **화자** | 누구의 말인가. 하나님 1인칭, 선지자, 백성의 말 인용, 반대자의 말 인용 |
| **전환** | 「그러나」「그러므로」「보라」「그 날에」. 탄식이 찬양으로, 심판이 회복으로 꺾이는 곳 |

여기에 구조 장치 셋을 더합니다. 화면에 도구 이름으로 내세우지는 않습니다. 원칙 문서대로 설명과 카드 배치에만 씁니다.

| 구조 | 뜻 | 카드에서 |
|---|---|---|
| **수미상관(인클루지오)** | 처음과 끝이 같은 말로 묶임 | 견주기 카드(echo) 하나: 첫 절 ↔ 끝 절 |
| **교차대구** | A–B–X–B′–A′, 가운데가 중심 | 표(table)의 가운데 열 강조(`mid`) |
| **삽입** | 흐름 사이에 끼어든 단락 | '배경'에서 앞뒤 흐름을 밝히고, 끼어든 단락을 '전환'으로 |

### 생략을 쓰는 규칙 (중요)
- 생략은 **틀이 먼저 세워진 곳에서만** 말합니다. 같은 모양이 두세 번 되풀이되어 독자가 다음 칸을 기대하게 된 뒤, 그 칸이 비거나 바뀌어야 생략입니다.
- 틀 없이 "본문이 말하지 않는다"고 하지 않습니다(공백 원칙과 같음).
- 카드에서는 **표 카드로 틀을 먼저 보여 주고, 빈 칸을 '눌러서 확인'** 하게 합니다. 하루 1곳의 '잠깐, 본문에서 확인하기'에 가장 잘 맞는 자리입니다.

## 2. 예언 — 반복과 생략이 중심 (목사님 지적)

선지서에는 같은 틀을 여러 번 돌리고 중요한 곳에서 깨는 본문이 많습니다. **다만 모든 예언 본문의 중심이 반복·생략은 아닙니다.** 후렴이 세워진 뒤 어긋나는 곳이 있을 때만 이 구조로 설명합니다. 듣는 사람은 리듬에 익숙해진 뒤 깨진 곳에서 멈추게 됩니다.

### 2-1. 반복의 종류
| 반복 | 예 (개역개정 대조함) |
|---|---|
| 전령 공식 | "여호와께서 이와 같이 말씀하시되", "여호와의 말씀이니라" |
| 후렴 | 사 9:12, 17, 21; 10:4 "그럴지라도 여호와의 진노가 돌아서지 아니하며 …"(4번)<br>암 4:6, 8, 9, 10, 11 "너희가 내게로 돌아오지 아니하였느니라"(5번)<br>겔 "너희가 나를 여호와인 줄 알리라"(58절) |
| 화 신탁 | 사 5:8, 11, 18, 20, 21, 22 "화 있을진저"(6번)<br>합 2:6, 9, 12, 15, 19(5번) |
| 문답 틀 | 말 1:2, 6, 12; 2:14; 3:7 "너희가 이르기를"(하나님의 말 → 백성의 반문 → 하나님의 답)<br>학 1:5, 7 "너희의 행위를 살필지니라" |
| 환상 틀 | 암 7:8; 8:2 "아모스야 네가 무엇을 보느냐"(보여 줌 → 물음 → 대답 → 풀이)<br>렘 1:11, 13 |
| 위로 공식 | 사 41:10, 13, 14; 43:1, 5; 44:2 "두려워하지 말라" |

### 2-2. 생략과 바뀜 (틀이 깨지는 자리)
| 본문 | 틀 | 깨진 곳 |
|---|---|---|
| **암 1–2** | 여덟 나라에 "서너 가지 죄로 말미암아"(1:3 … 2:6) → "불을 보내리니" | 이스라엘(2:6–16)에서 '불'이 빠지고, 죄의 목록이 길어지며 판결이 달라짐. 듣던 이스라엘이 마지막 대상이 됨 |
| **암 4** | 재앙 → "돌아오지 아니하였느니라" ×5 | 여섯째에는 재앙 대신 "네 하나님 만나기를 준비하라"(4:12) |
| **암 7–8** | 네 환상 | 앞의 둘은 아모스가 "사하소서/그치소서"(7:2, 5) 하고 여호와께서 "뜻을 돌이키셨"음(7:3, 6). 뒤의 둘(7:8; 8:2)에서는 아모스의 간구가 **빠지고**, 하나님이 먼저 "무엇을 보느냐" 물으심 |
| **욘 4:11** | 하나님의 물음 | 책이 하나님의 물음 "내가 어찌 아끼지 아니하겠느냐"로 끝남. 요나의 대답이 없음 |
| **미 6:3** | 소송 | "너는 내게 증언하라" — 백성의 증언이 기록되지 않음 |
| **렘 7:16; 11:14** | 선지자의 중보 | "너는 … 기도하지 말라" — 기대되는 중보가 금지됨 |
| **호 6:1–4** | 회개의 노래(화자는 논쟁이 있음 — 확정된 목소리로 표시하지 않음) | 바로 뒤 하나님의 답 "너희의 인애가 아침 구름이나 쉬 없어지는 이슬 같도다"(6:4). 화자 원칙과 겹침 |

### 2-3. 예언의 화자
- 한 장 안에서도 하나님 1인칭, 선지자 3인칭, 백성의 말 인용이 섞입니다. 카드에서는 인용마다 이름표를 붙입니다("하나님의 말씀", "백성의 말", "선지자의 말").
- 백성·반대자의 말(말라기의 "너희가 이르기를")은 붙잡을 말씀으로 삼지 않습니다. 생각거리(kwq)와 붙잡을 구절도 하나님의 말이나 선지자의 선포에서 고릅니다.

### 2-4. 예언 카드 흐름
| 이름표 | 내용 |
|---|---|
| 배경 | 누구에게, 어느 때(왕의 연대·포로 전후). 한 줄 |
| 고발 | 무엇을 하였나(죄의 목록·소송) |
| 심판 | 무엇이 오나(심판 공식) |
| 전환 | 틀이 깨지는 곳(2-2), 「그러나」「그 날에」 |
| 약속 | 회복, "두려워하지 말라" |
| 의미 | 표 카드로 틀과 빈 칸 견주기 |

모든 날에 이 순서를 다 쓰지 않습니다. 위로가 중심인 날(사 40–55)은 '배경 → 약속 → 전환 → 의미'로 씁니다.

## 3. 시
- **대구**: 같은 말을 둘째 줄이 되풀이·대조·발전시킴. 의미 카드는 대구 한 쌍을 견주기로.
- **목소리 바뀜**: 하나님께 말함(2인칭) ↔ 하나님에 대해 말함(3인칭), '나' ↔ '우리'. 바뀌는 곳이 전환입니다.
- **돌아서는 지점**: 탄식 → 신뢰·찬양(「그러나 나는」).
- **후렴·수미상관**: 시 8:1 ↔ 8:9, 시 42–43 "내 영혼아 네가 어찌하여 낙심하며"(42:5, 11; 43:5).
- **배치**: 앞뒤 시와의 자리(플롯유형 5-2 그대로).
- **거시 교차대구 — 여러 편이 한 묶음** (검토할 만한 가설입니다. 짝마다 본문 말로 성립하는지 확인하고, 다른 배열 가능성도 함께 봅니다. 가운데를 처음부터 강제하지 않습니다) (목사님 지적, 2026-10-28). 대표 예: **시 15–24** (365 통독 173일과 범위가 꼭 맞음)

  | D | 18 왕의 감사 | "기름 부음 받은 자에게 인자를 베푸심이여"(18:50) |
  | **X** | **19 하늘과 율법** | "하늘이 하나님의 영광을 선포하고"(19:1), "여호와의 율법은 완전하여"(19:7) |

  - 카드: 표 카드 하나로 아홉 칸을 보이고 가운데 열(19편)을 강조합니다(`mid`). 짝 하나(17:1 울부짖음 ↔ 22:24 울부짖을 때에 들으셨도다)는 견주기 카드로 둡니다.

## 4. 지혜
- **잠언**: 대조 대구는 서사 장면이 아니라 비교 단위입니다(10–29장). 하루 범위에서 **같은 주제의 잠언 두세 개를 모아** 견줍니다(말·게으름·부·친구). 짝을 이루는 상반된 잠언(26:4–5)은 '한쪽만 떼어 쓰지 않기'의 본보기입니다. 수미상관: 1:7 ↔ 31:30 '여호와를 경외함'.
- **전도서**: 후렴 "헛되고"(헤벨: '허무'로 단순화하지 않음), "해 아래", 「먹고 마시며 … 낙을 누리는 것」의 되풀이(2:24; 3:13; 5:18; 8:15; 9:7)
- **욥기**: 플롯유형 5-3 그대로(담화 표지, 서술자·하나님의 평가가 기준, 친구들의 말은 인물의 말)
- **카드 흐름**: 배경 → 대구(두 길) → 전환(뒤집는 잠언·질문) → 의미

## 5. 율법
- **대상**: 누구에게(제사장·백성·나그네·가난한 자)
- **조건**: "만일 …하면"의 갈래
- **예외와 배려**: 가난한 자는 비둘기(레 5:7; 12:8), 집의 물건을 먼저 비움(14:36). 틀 안에서 바뀐 칸이 곧 하나님의 마음을 보여 줍니다. 율법에서 '생략과 바뀜'이 쓰이는 자리입니다.
- **동기절**: 규정 끝의 이유. "나는 여호와이니라"(레 19), "너희도 애굽 땅에서 나그네가 되었었음이니라"
- **삽입된 이야기**: 레 10장 나답·아비후, 24:10–23 신성모독, 민 15:32–36 안식일. 규정 사이의 이야기는 내러티브 도구로 읽습니다.
- **카드 흐름**(앱이 알아듣게 고쳐 둠): 배경 → 규정(대상·조건) → 예외 → 이유(동기절) → 의미

## 6. 서신
- **흐름**: 문제 → 주장·근거 → 대조 → 권면(시험날 문서 그대로)
- **전환어**: 「그러므로」. 직설(하나님이 하신 일)에서 명령(그러니 이렇게 살라)으로 넘어가는 곳(롬 12:1; 엡 4:1)
- **인용된 말**: 고린도 교인들의 말을 인용하고 바울이 답함(고전 6:12; 7:1). 화자 원칙대로 이름표를 붙입니다.
- **목록**: 육체의 일과 성령의 열매(갈 5:19–23)는 대조 표 카드로
- **수미상관**: 롬 1:5 ↔ 16:26 "믿어 순종하게"
- **카드 흐름**: 배경(보내는 이·받는 교회·문제) → 주장 → 근거 → 전환(그러므로) → 권면 → 의미

## 7. 묵시(요한계시록)
- **일곱 겹 반복**: 일곱 교회, 일곱 인, 일곱 나팔, 일곱 대접. 일곱 교회의 후렴은 "귀 있는 자는 성령이 교회들에게 하시는 말씀을 들을지어다"(2:7 … 3:22, 7번)
- **삽입**: 여섯째와 일곱째 사이(7장; 10:1–11:14)에 끼어든 장면
- **듣다 ↔ 보다**: 5:5 들은 것(유다 지파의 사자) ↔ 5:6 본 것(어린 양)
- **두 성의 대조**: 17–18장 큰 성 바벨론 ↔ 21장 새 예루살렘
- **카드 흐름**: 배경 → 본 것 → 들은 것 → 전환(삽입) → 의미

2. **앱의 이름표 목록을 넓힙니다.** 지금은 배경·긴장·전환·의미·규정·이유·지시·목적·되풀이·예외·완성까지 알아듣습니다. 여기에 고발·심판·약속·호소·찬양·대구·주장·근거·권면·본 것·들은 것을 더합니다(그림 묶음에 쓰임).
3. **생략 표 카드 양식**: 틀(같은 공식의 행 여러 개) + 마지막 행 강조(`hl`) + '먼저 비교해 보고, 달라진 칸 보기'. 지금 있는 표 카드로 바로 됩니다. 암 1–2를 첫 본보기로 만들 수 있습니다.
4. **도전 탭**: 예언·시 날에는 '장면 순서'가 나오지 않습니다(이미 이야기 본문만 냄). 앞으로 '되풀이되는 말'을 후렴 찾기로 바꾸면 이 원칙과 이어집니다(공개 뒤 과제).
5. **읽기 질문(LENSES)**: 예언에 "같은 말이 몇 번 되풀이되나요? 그 틀이 깨지는 곳은 어디인가요?"를 더합니다.

## 9. 정한 것 (목사님, 2026-10-28)
- 예언 카드 이름표: **고발 · 심판 · 약속** (앱이 알아듣게 고쳐 둠)

## 10. 교정 (GPT, 2026-10-28)
- 모세·선지자·사도의 말도 문맥에서 성격을 판정합니다: 하나님의 말을 전하는지, 자기 판단을 말하는지, 상대의 말을 인용하는지.
- 아침·밤 같은 때 표지와 생략은 자동으로 상징·공백이 되지 않습니다. 문맥이 기대를 세웠을 때만 씁니다.
