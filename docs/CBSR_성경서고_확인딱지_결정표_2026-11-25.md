# CBSR 성경 서고 '확인' 딱지 결정표

2026-11-25. 로드맵 4단계의 원고 일입니다. 작업대에 '확인' 딱지가 남은 책은 열두 권(딱지 열세 개)입니다. 딱지는 앱 화면에는 나오지 않고 작업대에만 보입니다.

목사님이 정하시면 원고를 고치고 딱지를 뗍니다. 칸마다 Claude의 제안을 붙였습니다.

## 가. 시기가 비어 있는 다섯 권

시기 칸이 비면 표지에서 '시기' 줄이 보이지 않습니다. 화면이 깨지지는 않습니다.

| 책 | 본문이 알려 주는 것 | 제안 |
|---|---|---|
| 베드로전서 | "바벨론에 있는 교회"와 마가의 문안(벧전 5:13), 실루아노가 도움(5:12) | 시기: **베드로가 '바벨론'에 있을 때**. 각주: 바벨론을 로마로 보는 것은 초대 교회부터 이어진 견해입니다. |
| 요한일서 | 때를 알려 주는 말이 없음 | **비워 둠** |
| 요한이서 | 때를 알려 주는 말이 없음 | **비워 둠** |
| 요한삼서 | 때를 알려 주는 말이 없음 | **비워 둠** |
| 유다서 | 때를 알려 주는 말이 없음 | **비워 둠** |

요한 서신 세 권에 '요한복음보다 뒤'라고 적는 길도 있습니다. 다만 본문에서 나온 말이 아니라 전통에서 나온 말입니다.

## 나. 목사님 논문에서 옮긴 문장 (목사님만 확인하실 수 있음)

| 책 | 지금 원고 | 보실 것 |
|---|---|---|
| 역대상 | 목적: 포로에서 돌아온 백성이 다윗 언약을 붙들고 제사장과 레위인의 섬김을 따라 예배하는 공동체로 서게 함. 주제: 다윗 언약 · 예배하는 공동체 · 제사장과 레위인의 섬김 | 「역대기의 족보에 나타난 포로기적 비전」과 맞는지 |
| 역대하 | 21–24장 마디: 다윗 왕조의 위기와 여호야다, 요아스. 주제: 다윗 언약 · 제사장과 왕의 협력 · 예배의 회복 | 「역대기의 포로기적 비전」과 맞는지 |
| 욥기 | 목적: 욥과 친구들의 말을 하나님의 말씀과 대조하여, 사람의 판단을 넘어 다스리시는 하나님을 알게 함 | 「하나님과 욥」과 맞는지. 하나님의 세 말씀(38–39장, 40:1–2, 40:6–41:34)과 42:6 풀이를 화면에 얼마나 실을지 |
| 시편 | 1권을 1–2 / 3–14 / 15–24 / 25–37 / 38–41편으로 묶고 8편과 19편을 비교하는 읽기 | 목사님 논문과 맞는지 |
| 다니엘 | 2장, 7장, 8장 차례로 새로 알려 주는 것을 모으는 읽기 | 목사님 보론과 맞는지. 네 왕국 설명을 어디까지 실을지 |

제안: 욥기와 다니엘의 '화면에 얼마나 실을지'는 지금처럼 싣지 않기를 권합니다. 서고의 개론은 먼저 읽는 참고 자료라서, 풀이가 들어가면 통독하며 스스로 발견할 몫이 줄어듭니다.

## 목사님 결정 (11-25) — 반영함

- 가: 제안대로. 베드로전서 시기 "베드로가 '바벨론'에 있을 때"와 각주를 넣고, 요한 서신 세 권과 유다서는 비워 둠.
- 나: 모두 목사님 원고에서 온 것이 맞음. 욥기·다니엘의 풀이는 싣지 않음.
- 다: 창세기 일곱 마디 맞음. 야고보서는 "예수님을 닮았다는 말은 넣으세요. 아주 멋드러진 상상이라고 생각합니다." → 연결 칸 끝 문장을 "예수님을 직접 보고 들은 사람이 많던 때입니다. 얼굴과 목소리마저 형을 닮았을 주님의 형제가 예수님의 말씀으로 권하니, 듣는 이들은 그분을 떠올렸을 것입니다."로 고침. 본문이 말한 것이 아니라 그려 본 것임이 드러나게 '닮았을', '떠올렸을 것입니다'로 씀.
- 작업대의 '확인' 딱지는 이제 하나도 없습니다.
