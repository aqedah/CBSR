# CBSR 윤문 기준 — 문장 교정과 사용례 (2026-11-24)

가이드북 세션에서 목사님이 짚으신 문장들을 모아, 윤문 세션이 같은 기준으로 고칠 수 있게 정리했습니다. 앞선 기준(`CBSR_목사님문체지침_2026-11-13`, `CBSR_문장연결_작성지침_2026-11-20`, `CBSR_원고교정_원칙과_결과_2026-11-12`, `CBSR_체험판_원고고치기_전수조사_2026-11-14`)과 함께 씁니다. 겹치는 것은 짧게 적고, 이번에 새로 잡힌 것은 사용례를 붙였습니다.

수집한 고칠 문장 목록은 `CBSR_윤문후보_수집_2026-11-24`에 있습니다.

## 0. 먼저 지킬 것
- 개역개정 인용(큰따옴표 안)은 고치지 않습니다. 글자가 다르면 개역개정대로 되돌립니다.
- 목사님이 쓰신 문장(책머리 f0, 도구 풀이, 목사님 원고에서 온 해설·기도·성경 전체로, 2027 4일 원고 전체)은 고치지 않고 의견만 남깁니다. 목사님이 고치라고 하신 곳만 고칩니다.
- 뜻과 해석, 물음의 방향은 바꾸지 않습니다. 뜻이 걸리면 '확인할 것'으로 따로 둡니다.
- 읽는 사람 기준: 교회 성도가 앞뒤 없이 이 문장만 읽고 뜻을 한 번에 말할 수 있는가.

## 1. 낱말 고르기 — 고유어만 고집하지 않습니다

목사님 말씀: "비교한다는 말을 견주다로 쓰네요"(11-16), "'은사의 쓸모를 재는 말'은 대체 뭔가요. 너 진짜 단어와 어휘 선택 이상하네요"(11-24).

영어 분석 낱말(compare, measure, contrast, frame…)을 고유어로 옮기면서 생긴 말들입니다. 무엇을 하라는지, 무엇을 가리키는지 바로 보이는 말로 씁니다.

| 쓰지 않는 말 | 쓰는 말 | 사용례 |
|---|---|---|
| 견주다 | 비교하다 | "견주어 보세요" → "비교해 보세요" |
| 재다(쓸모를 재다, 숫자로 재다) | 무엇을 위한 것인지 바로 씀 | "14장에서 은사의 쓸모를 재는 말은 무엇입니까?" → "바울은 은사를 무엇을 위하여 쓰라고 합니까?" / "바울은 은사가 교회를 세우는지를 물어 그 쓸모를 잽니다" → "은사는 교회의 덕을 세우라고 주신 것입니다" |
| 쓸모(사람을 쓸모로 보다) | 유익, 쓰임, 또는 풀어 씀 | "쓸모로 사람을 재지 않게" → "사람을 얼마나 유익한지로만 보지 않게" |
| 세다(은혜를 세다, 받은 것을 센다) | 기억하다, 감사하다, 붙들다 | "그 은혜를 세어 보게 하소서" → "그 은혜를 기억하게 하소서" |
| 꺼내다(말씀을 꺼내다) | 인용하다, 들다, 말하다 | "바울은 이 말씀을 꺼냅니다" → "바울은 이 말씀을 인용합니다" |
| 맞서다, 맞세우다(대조 뜻) | 대조하다, 나란히 놓고 비교하다, 짝을 이루다 | "율법의 행위와 믿음을 맞세우며" → "율법의 행위와 믿음을 나란히 놓고 비교하며" (실제로 맞선 일은 그대로: "사도끼리 맞서는 일") |
| 되풀이 | 반복 | "되풀이됩니다" → "반복됩니다" (책머리 f0의 목사님 문장은 그대로) |
| 서술자 | 본문은 | "서술자가 끼어들어 한 말입니다" → "본문이 끼어들어 설명합니다" |
| 써서(도구로) | 사용하여 | "도구를 써서" → "도구를 사용하여" |

## 2. 흐린 비유를 사실로

추상 비유(자리, 길, 무게, 결, 선, 줄, 뿌리, 매듭, 마디)로 생각을 압축하지 않습니다. 가리키는 것이 바로 보일 때만 씁니다.

| 쓰지 않는 말 | 사용례 → 고친 문장 |
|---|---|
| ~의 줄('죽음의 줄') | 11-23 목사님: "'줄'이라는 표현이 되게 어색하네요" → "죽음이 이어집니다" |
| 뿌리 | "고린도 교회가 갈라진 뿌리는 무엇입니까?" → "고린도 교회가 갈라진 까닭은 무엇입니까?" |
| 매듭, 마디 | "두 번의 매듭은 같은 말로 시작합니다" → "바울이 두 번 크게 정리하는 곳은 같은 말로 시작합니다" |
| 길을 열다 | "'자백하면' 하고 길을 엽니다" → "1:9에서 자백하는 사람에게 주시는 약속을 말합니다" |
| 꿰다 | "사람의 악까지 꿰어" → "사람의 악까지" |
| ~이 …이 되다(복음이 이름이 되다) | "16장에서 이 복음은 27명의 이름이 됩니다" → "16장에서 바울은 27명의 이름을 하나하나 부르며 문안합니다" |
| 내려오다, 눈이 옮겨 가다, 꿰뚫다, 자리를 맞바꾸다 | 11-14 전수조사에서 지운 말들. 다시 쓰지 않습니다. |

## 3. 문장 짜기

**① 가리키는 말의 앞말이 분명해야 합니다.** (11-24, 12/7 해설)
- 고치기 전: "성령의 열매는 하나입니다. 반면에 '육체의 일'에서 '일'은 여럿입니다. 무슨 뜻일까요? 성령을 따라 사는 삶 전체에서 이 성품들이 함께 맺힙니다."
- 문제: '이 성품들'이 바로 앞의 '육체의 일'을 가리키는 것처럼 읽힙니다. 두 말을 비교한 뒤 그 차이를 설명하는 문장이 빠졌습니다.
- 고친 뒤: "육체의 일은 음행에서 방탕함까지 하나하나 따로 터져 나오는 행위들입니다. 성령의 열매는 다릅니다. 사랑과 희락과 화평부터 온유와 절제까지 아홉 가지가 한 열매에 함께 맺힙니다."

**② 설명하다 만 해설을 남기지 않습니다.** 질문을 던졌으면 답하고, 근거를 들었으면 결론까지 잇습니다. (11-24, 11/30 해설: "설명하다 만 느낌")

**③ 한 문장 안에서 주어가 바뀌지 않게 합니다.**
- "하늘이 열려 환상을 보고, 베드로가 입을 열어 깨달음을 말하며, 옥문이 열려 밖으로 나옵니다." → 보는 이, 나오는 이를 밝혀 나눕니다.

**④ 주어를 밝힙니다.** 칸 첫 문장일수록 그렇습니다.
- "바울의 마지막 편지로 봅니다." → "디모데후서는 바울의 마지막 편지입니다."
- "답을 적지 않았지만 읽는 사람은 압니다." → "바울은 답을 적지 않습니다. 그래도 읽는 사람은 답을 압니다."

**⑤ 서술어 없이 낱말만 두고 끝내지 않습니다.** "우물가의 만남(29:2–12)." → "29:2–12에서 야곱은 우물가에서 라헬을 만납니다."

**⑥ 줄표와 가운뎃점으로 압축하지 않습니다.** 지면 장치(말뜻의 '낱말 — 풀이', 성품 꼬리표)는 둡니다. 문장 안의 "개구리·이·파리"는 "개구리와 이와 파리"로 씁니다.

**⑦ 본문이 말하지 않은 일반화와 판정하는 부사를 쓰지 않습니다.** "늘", "어리석게도" 같은 말은 본문 근거가 있을 때만 씁니다.

## 4. 하루 한 줄기 — 칸끼리 이어져야 합니다

목사님 말씀(11-24, 11/29): "적용은 '피할 길'과 '양보'가 따로 놉니다. 안 이어져요." "피할 길 한 줄로는 8–10장을 다 아우르기 어렵습니다."

- 대표 표시 → 본문 관찰 → 하나님의 성품 → 적용 → 기도 → 해설이 같은 줄기여야 합니다. 한 칸만 고치면 다른 칸과 어긋납니다. 고칠 때는 하루 전체를 같이 봅니다.
- 하나님의 성품 물음은 내 삶의 자리에서 시작해도 됩니다. 사용례: "요즘 나에게 닥친 시험은 무엇입니까? 시험 당할 즈음에 **피할 길을 내시는 하나님의 은혜**가 내게는 어떻게 다가옵니까?"
- 적용의 앞 문장은 하나님이 하신 일이고, 굵은 물음은 거기서 바로 나옵니다. 둘째 물음(→)은 할 일을 묻습니다. "하나님은 나를 어떤 마음으로 보실까요?"처럼 짐작을 묻지 않습니다.
- 한 줄기로 묶기 어려운 넓은 범위는 세 장을 묶는 틀을 찾습니다. 사용례(고전 8–10): 8:1 "사랑은 덕을 세우나니" … 10:23 "모든 것이 덕을 세우는 것은 아니니" 사이에 약한 형제(8:11) → 쓰지 않은 권리(9:12) → 남의 유익(10:24).
- 서로 독립된 단락이 여럿인 날은 관찰·성품을 가·나 두 갈래로 둡니다(`CBSR_범위넓은날_관찰성품_두갈래_검토_2026-11-24`).

## 6. 표기 통일
- 원고 문장은 현행 맞춤법, 인용은 개역개정: "값없이"(원고) / "값 없이"(인용), "화목 제물", "어린 양"(개역개정 띄어 씀).
- 한 장짜리 책: "요이 7절", "몬 18절"(요이 1:7처럼 쓰지 않음).
- 맞춤법 자주 틀리는 것: 내딛을 → 내디딜.
- 날짜·날 번호를 원고 안에서 부를 때는 통독표 판이 바뀌면 함께 고칩니다(예: 2027 19일 "15일에 본 요셉의 울음" → 5판에서는 17일).
