## 0. 방식 결정: 정해진 양식으로 GPT가 쓰고, Claude가 넣는다

**검토 페이지(jan.html·feb.html, 카드 보며 메모 켜기)는 원고를 쓰는 곳으로 쓰지 않습니다. 목사님이 고친 원고를 확인하고 승인하는 곳으로만 씁니다.**

이유는 세 가지입니다.

1. 검토 페이지는 날짜와 카드에 짧은 메모를 다는 도구입니다. 카드 여러 장을 바꾸거나 날 전체를 다시 쓰는 일을 담기에는 칸이 맞지 않습니다.
2. 원고는 `story_cards.json`의 정해진 구조(카드 종류, 인용 상자, 표, 견주기)로 들어가야 앱에 그대로 나옵니다. 정해진 양식으로 받아야 Claude가 손으로 옮겨 적다가 틀릴 일이 없습니다.
3. 양식으로 받으면 넣기 전에 자동 검사를 할 수 있습니다. 인용문이 개역개정과 같은지, 장절이 맞는지, 카드 구조가 맞는지 확인합니다.

### 흐름

1. GPT가 아래 양식으로 JSON 파일을 씁니다. 하루에 파일 하나입니다.
2. 목사님이 그 파일을 Claude에게 넘깁니다.
3. Claude가 검사합니다(인용 대조, 구조, 목회적 안전 경고). 문제가 있으면 GPT에게 돌려보낼 목록을 만듭니다.
4. Claude가 원고에 넣고 사이트를 다시 만듭니다. 그날은 상태표에 'GPT 수정'으로 표시합니다.
5. 목사님이 검토 페이지와 앱의 스토리 QT로 확인합니다. 메모가 있으면 다시 2번으로 갑니다.
6. 목사님이 승인하면 상태표에 '승인'으로 표시합니다. 원고가 다시 바뀌면 상태가 저절로 '다시 검토'로 돌아갑니다.

## 2. 제출 양식

하루에 JSON 파일 하나를 냅니다. 파일 이름은 `CBSR_원고수정_032.json`처럼 날 번호를 세 자리로 씁니다. **txt로 내도 됩니다. 내용만 JSON이면 됩니다.**

### 2-1. 날 전체를 다시 쓸 때 (32·38일)

```json
{
  "day": 32,
  "pv": "A",
  "why": "33장의 임재 위기와 중보를 넣고, 두 번의 이른 아침을 대조함",
  "replace_day": {
    "type": "T2",
    "type2": "T4",
    "t2": "한 줄 구조 설명",
    "key": "핵심 낱말 하나",
    "spine": "중심 질문",
    "kwq": {"q": "나의 생각거리", "r": [2, 33, 14]},
    "cards": [ /* 카드 9–12장, 아래 2-3 규칙 */ ],
    "qt": {
      "guide": {"today": "오늘 본문 소개 2–3문장", "find": "읽으며 찾아볼 것 1문장"},
      "obs": {"q": "관찰 질문 (장절)", "look": [{"t": "짧은 인용", "r": [2, 33, 3], "n": "살펴볼 점"}]},
      "god": "하나님은 어떤 분인가 (본문 근거와 장절)",
      "christ": "정경 연결 — 본문이 직접 이어질 때만. 억지로 쓰지 않음, 없으면 빈 문자열",
      "ck": "quote",
      "apply": "적용 질문 하나",
      "pray": "기도 2–3문장 (끝맺음 말은 앱이 붙임)"
    }
  }
}
```

### 2-2. 카드 몇 장만 고칠 때 (나머지 날)

카드 번호는 **지금 원고의 순서(0부터, 표지가 0)**입니다. 바꾸는 카드는 **카드 전체를 다시 적어** 주세요. 일부 글만 적으면 안 됩니다.

```json
{
  "day": 7,
  "pv": "A",
  "why": "21:14와 22:3의 두 아침을 견주기 카드로",
  "replace_cards": { "3": { /* 바뀐 카드 전체 */ } },
  "insert_after":  { "2": [ { /* 새 카드 */ } ] },
  "delete_cards":  [],
  "set": { "qt.apply": "…", "qt.pray": "…", "spine": "…" }
}
```

- `replace_cards`, `insert_after`, `delete_cards`, `set`은 필요한 것만 씁니다.
- 번호는 모두 고치기 전 원고 기준입니다. Claude가 순서를 맞춰 넣습니다.
- `set`에 쓸 수 있는 것: `spine`, `t2`, `key`, `kwq.q`, `kwq.r`, `qt.guide.today`, `qt.guide.find`, `qt.obs.q`, `qt.god`, `qt.christ`, `qt.apply`, `qt.pray`

### 2-3. 카드 규칙

| 종류 `k` | 쓰는 자리 | 필드 |
|---|---|---|
| `cover` | 맨 앞 1장 | `kick`(책 장: "출애굽기 32–34장"), `h`(제목, 줄바꿈 `\n` 한 번), `sub`(물음 두 줄) |
| `full` / `split` | 설명 카드 | `lab`, `h`, `b` |
| `quote` | 한 구절을 크게 | `lab`, `b`(짧은 도입), `big`(인용), `ref`("출 34:6 중" 처럼) |
| `echo` | 두 구절 견주기 | `lab`, `h`, `pair`, `b`, 필요하면 `reveal: true` |
| `table` | 표 | `lab`, `h`, `tbl: {h:[열 이름], rows:[[행 이름, 칸, 칸…]], hl:[[행,칸]], mid: 가운데 열 번호}`, `note` |

- **`lab`**: "배경 · 제목", "긴장 · 제목", "전환 · 제목", "의미 · 제목"처럼 네 단계 낱말로 시작합니다. 뒤에 " · 33:12–17"처럼 장절을 붙여도 됩니다.
- **`b`**: 문단 배열입니다. 문자열은 설명이고, `{"q": ["인용", "출 33:14"]}`는 말씀 상자입니다.
  - 말한 사람 이름표를 붙이려면 세 번째 칸을 씁니다: `{"q": ["내가 친히 가리라", "출 33:14", "하나님의 말씀"]}`.
  - 서술자의 문장이면 이름표를 비워 둡니다. 앱이 대화가 없는 절에 '본문의 설명'을 저절로 붙입니다.
- **`echo`의 `pair`**: `[["다윗: \"… __밑줄__ …\"", "24:17 · 굴 밖에서 사울이 한 말", "이름표(선택)"], [ … ]]`. 견줄 낱말은 `__밑줄__`로 표시합니다. `reveal: true`이면 먼저 비교하게 하고 버튼을 누르면 설명이 보입니다.
- **인용문은 개역개정 그대로** 씁니다. 줄인 곳은 `…`로 표시합니다. 넣기 전에 Claude가 성경 본문과 글자 대조를 하고, 다르면 돌려보냅니다.
- **장절 표기**
  - 그날 읽는 범위 안이면 글 속에 `(33:14)`처럼 씁니다. 앱이 누르면 구절이 열리게 합니다.
  - 다른 책이면 `(고전 10:7)`처럼 책 약칭을 붙입니다.
- **길이**: 카드 한 장의 글(인용 포함)은 120자 안팎, 많아도 200자를 넘지 않게 합니다. 한 날은 9–12장입니다.
- **`img`**: 비워 둡니다. 그림은 앱이 카드 글을 보고 고릅니다.
- **강조**: `**굵게**`는 한 카드에 한 번 정도만 씁니다.

## 3. 내용 원칙 (원칙 문서 요약)

- 인물의 말과 서술자의 말을 구분합니다. 인물이 하나님을 말했다고 그 사람의 주장이 하나님의 판단이 되지는 않습니다.
- 본문이 말하지 않는 심리와 동기를 채우지 않습니다.
- 표지의 질문은 마지막 의미 카드와 생각거리(kwq)에서 회수합니다.
- 카드는 다음 카드의 이해에 이바지해야 합니다. 다 본 뒤 하나의 이야기로 기억되게 합니다.
- 적용은 그날 이야기에서 나와야 합니다. 인물을 무조건 본받으라고 하거나, 모든 날을 같은 권면으로 맺지 않습니다.
- 질병·출산·몸의 상태를 죄와 잇지 않습니다. 폭력을 본받을 행동으로 쓰지 않습니다.
- 정경 연결(christ)은 본문이 직접 이어질 때만 씁니다.
