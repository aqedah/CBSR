# 읽다가 궁금한 점 — 원고 보관 (아직 앱에 넣지 않음)

목사님이 공개 범위를 정하시면 접어 보는 설명으로 붙입니다.

## 2월

메인 이야기 카드에 본문 전승 논의를 길게 넣지 않는다. ‘읽다가 궁금한 점’처럼 원할 때 펼치는 짧은 설명이 적절하다. 아직 그런 기능이 없다면 설명 원고를 먼저 보관하고, 기능을 만들기 위해 카드 구조 전체를 바꾸지 않는다.

### 5.1. 44일 — 드우엘과 르우엘은 누구인가요?

**독자용 제안 문안**

> 민수기 1:14은 갓 지파 지휘관 엘리아삽의 아버지를 ‘드우엘’, 2:14은 ‘르우엘’이라고 적습니다. 같은 인물을 가리키는 자리에서 이름의 표기가 다릅니다. 히브리어 사본과 고대 번역에도 표기 차이가 전해지며, 번역에 따라 한 이름으로 맞추기도 합니다. 이 앱은 각 절의 개역개정 표기를 그대로 따릅니다.

**편집자 메모**

개역개정의 데이터 오기로 처리하지 않는다. NET의 민 2:14 본문 주석은 레닌그라드 사본/BHS의 르우엘 표기와, 여러 히브리어 사본·사마리아오경·라틴어역을 따라 드우엘을 택하는 번역 결정을 설명한다. 두 이름을 앱이 임의로 통일하지 않는다. ‘두 사람이기 때문이다’ 또는 ‘필사자가 틀렸음이 확실하다’고 확정하지 않는다. [NET 민 2:14 본문 및 주석](https://classic.net.bible.org/verse.php?book=Num&chapter=2&verse=14)

### 5.2. 45일 — 레위인의 수를 더하면 왜 총수와 다른가요?

| 본문 | 항목 | 수 |
| --- | --- | ---: |
| 민 3:22 | 게르손 종족 | 7,500 |
| 민 3:28 | 고핫 종족 | 8,600 |
| 민 3:34 | 므라리 종족 | 6,200 |
| 위 세 수의 합 | 산술 합계 | 22,300 |
| 민 3:39 | 본문이 제시한 총수 | 22,000 |
| 차이 |  | 300 |

**독자용 제안 문안**

> 세 종족의 수를 더하면 22,300명이지만, 3:39에 적힌 총수는 22,000명입니다. 이 차이가 생긴 이유는 이 대목에 설명되어 있지 않습니다. 이어지는 규례는 레위인 22,000명과 이스라엘의 맏아들 22,273명의 차이인 273명에 대해 속전을 내도록 합니다(3:43–50). 앱은 숫자를 임의로 맞추지 않고 개역개정 그대로 제시합니다.

**편집자 메모: 소개할 수 있는 설명과 한계**

1. 유대 해석 전통에는 300명을 레위인 가운데 맏아들이었던 사람들로 보아, 다른 맏아들을 대신하는 수에서 제외되었다고 설명하는 해석이 있다. 『베코롯』 5a에 전해지는 설명이다. **민수기 본문이 300명의 신분을 직접 밝혔다는 뜻은 아니다.** [베코롯 5](https://www.sefaria.org/Bekhorot.5)
2. 일부 칠십인역 사본에는 고핫 종족의 수가 8,600 대신 8,300으로 전한다. 이 수를 따르면 세 종족의 합이 22,000이 된다. **일부 사본의 이문이며, 모든 칠십인역 사본의 수가 같다고 쓰지 않는다.** 이를 이유로 앱의 개역개정을 8,300으로 수정하지 않는다. [NIV 민 3:28 본문 및 각주](https://www.biblegateway.com/passage/?search=Numbers+3:28&version=NIV)

두 설명 중 하나를 본문의 확정된 정답으로 선택할 필요는 없다. ‘단순 반올림’으로 처리하지도 않는다. 이야기 카드가 현재 사용하는 22,000명·22,273명·273명은 각 인용 본문과 일치하므로 그대로 둔다. 속전 계산은 273 × 5 = 1,365세겔이다(3:47, 50). [대한성서공회 민수기 3장](https://www.bskorea.or.kr/bible/korbibReadpage.php?book=num&chap=3&sec=1&version=GAE)
