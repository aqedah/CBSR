# 성경 통독 원고 윤문·교정·검수 요청 (Gemini)

## 1. 이 원고는 무엇인가

**CBSR(이야기통독)**은 한국의 한 교회(중앙성서교회)에서 이삭 목사가 기획하고 총괄하는 성경 통독 앱과 가이드북입니다. 교인들이 날마다 성경을 읽고, 읽은 본문을 스스로 관찰하고 묵상하도록 돕습니다. 성경은 한국어 **개역개정**을 씁니다. 성경을 이야기로 읽는 방법(내러티브 비평)을 바탕으로 합니다.

첨부한 파일은 **12월 체험판 49일 원고 전체**입니다(사도행전부터 요한계시록까지). 앱과 인쇄 가이드북이 같은 원고를 씁니다.

**읽는 사람**은 교회 성도입니다. 신앙을 갓 시작한 사람, 통독을 처음 하는 청년, 신학 용어를 모르는 어른이 읽고 이해해야 합니다.

- 첨부 파일: `CBSR_12월체험판_원고전체_검수용_2026-11-26.csv`
  - 1,510줄, 약 8만 6천 자
  - 열: 번호, 날, 칸, 칸 경로, 원문, 표시
- 앱: https://aqedah.github.io/CBSR/try.html

## 2. 부탁하는 일 세 가지

1. **윤문:** 성도가 앞뒤 없이 그 문장만 읽고도 뜻을 한 번에 말할 수 있게 다듬습니다.
2. **교정:** 맞춤법, 띄어쓰기, 문장 부호, 장절 표기를 바로잡습니다.
3. **검수:** 사실, 성경 인용, 장절이 맞는지 봅니다. 한 날의 칸들이 같은 이야기로 이어지는지도 봅니다.

**고칠 것이 없는 줄은 결과에 넣지 마십시오.** 바꿀 줄만 적습니다.

## 3. 먼저 지킬 것

1. **개역개정 인용은 고치지 않습니다.** 큰따옴표 안의 성경 말씀은 옛말, 띄어쓰기, 문장 부호까지 개역개정 그대로입니다. 예: "값 없이", "함께 하시므로". 다만 개역개정과 글자가 다르다고 판단되면 '사실' 판정으로 알려 주십시오. 확실하지 않으면 '확인 필요'로 적습니다.
2. **표시 열에 '목사님 문장'이라고 적힌 줄은 고치지 않습니다.** 의견만 남깁니다. 책머리(날 열이 f0~f4인 줄)도 목사님 문장이 많으니 꼭 필요할 때만 의견을 줍니다.
3. **뜻, 해석, 물음의 방향은 바꾸지 않습니다.** 해석이 의심스러우면 고치지 말고 '확인 필요'로 적습니다.
4. **길이를 크게 늘리지 않습니다.** 인쇄 지면이 정해져 있습니다. 한 칸에서 고친 글자가 원문의 30%를 넘지 않게 하십시오. 해설은 한 칸 330자, 성경 전체로는 160자를 넘지 않게 합니다(지금 가장 긴 칸이 각각 332자, 158자).
5. **'서술자'는 바꾸지 않습니다.** "서술자가 끼어들어 한 말입니다"처럼 등장인물과 이야기하는 이의 목소리를 구별하는 말입니다. '본문'으로 바꾸면 어감이 달라집니다. '본문'은 글 전체를 가리킬 때만 씁니다.
6. **지면 장치는 그대로 둡니다.**
   - 도구 기호(◆ 반복, ⇔ 대조, ▲ 전환, ● 열쇠말, ≒ 비유, □ 틀, ∥ 평행 등)
   - 굵게(`**…**`)와 중괄호 표시(`{동그라미}`, `{물결 밑줄}`)
   - 말뜻의 '낱말 — 풀이'
   - 성품 꼬리표
   - 장면 나눔·다시 읽을 곳 같은 짧은 이름표

## 4. 말투

- **기본은 합니다체입니다.** 문장은 '-입니다/-습니다'로 마칩니다. '-는 겁니다'는 여운을 남길 곳에만 드물게 씁니다(한 칸에 많아야 하나).
- **해설과 성경 전체로는 목사님 말투입니다.**
  - 사이사이 '~지요'를 섞습니다.
  - 스스로 묻고 바로 답합니다. 예: "그렇다면 누가는 왜 결말을 적지 않았을까요? 1:8의 땅 끝은 아직 남아 있기 때문입니다."
  - '우리'로 오늘과 잇습니다.
  - 해설의 맺음은 "하나님은 ~분입니다."입니다.
- **짧은 칸은 담백하게 씁니다.** 오늘의 흐름, 말뜻, 성경 읽기 표시, 눈여겨볼 것, 본문 관찰, 적용, 소제목이 여기에 들어갑니다. 이 칸에는 '~지요', '우리', '-겁니다'를 넣지 않습니다.
- **기도:**
  - 하나님께 '-소서'로 아룁니다. '-십시오'와 섞지 않습니다.
  - 1인칭은 '제'로 씁니다.
  - 기도 안에 장절을 넣지 않습니다.
  - 끝은 반드시 "예수님의 이름으로 기도합니다. 아멘."입니다.

## 5. 낱말 고르기 — 고유어만 고집하지 않습니다

영어 분석 낱말을 고유어로 옮기면서 생긴 어색한 말이 남아 있을 수 있습니다. 무엇을 하라는지, 무엇을 가리키는지 바로 보이는 말로 바꿉니다.

| 쓰지 않는 말 | 쓰는 말 | 예 |
|---|---|---|
| 견주다 | 비교하다 | "견주어 보세요" → "비교해 보세요" |
| 재다(쓸모를 재다) | 무엇을 위한 것인지 바로 씀 | "은사의 쓸모를 재는 말" → "바울은 은사를 무엇을 위하여 쓰라고 합니까?" |
| 쓸모(사람을 쓸모로 보다) | 유익, 쓰임 | "쓸모로 사람을 재지 않게" → "사람을 얼마나 유익한지로만 보지 않게" |
| 세다(은혜를 세다) | 기억하다, 감사하다, 붙들다 | "그 은혜를 세어 보게 하소서" → "그 은혜를 기억하게 하소서" |
| 꺼내다(말씀을 꺼내다) | 인용하다, 들다, 말하다 | "이 말씀을 꺼냅니다" → "이 말씀을 인용합니다" |
| 맞서다, 맞세우다(대조의 뜻) | 대조하다, 나란히 놓고 비교하다 | 실제로 맞선 일("아모스와 아마샤가 맞섭니다")은 그대로 |
| 되풀이 | 반복 | 목사님 문장은 그대로 |
| 써서(도구를) | 사용하여 | |

글자 그대로의 뜻은 그대로 둡니다. 예를 들어 실제로 수를 세는 말("몇 번 나오는지 세어 보세요"), 다림줄로 '재다', 인물이 "이야기를 꺼냅니다"가 그렇습니다.

## 6. 흐린 비유를 사실로

자리, 길, 무게, 결, 선, 줄, 뿌리, 매듭, 마디 같은 추상 비유로 생각을 압축하지 않습니다. 가리키는 것이 바로 보일 때만 씁니다.

- "고린도 교회가 갈라진 뿌리는 무엇입니까?" → "고린도 교회가 갈라진 까닭은 무엇입니까?"
- "두 번의 매듭은 같은 말로 시작합니다" → "바울이 두 번 크게 정리하는 곳은 같은 말로 시작합니다"
- "16장에서 이 복음은 27명의 이름이 됩니다" → "16장에서 바울은 27명의 이름을 하나하나 부르며 문안합니다"
- "'죽음의 줄'이 이어집니다" → "죽음이 이어집니다"

## 7. 문장 짜기

1. **가리키는 말의 앞말이 분명해야 합니다.** '이것', '그 일', '이 성품들'이 바로 앞에서 무엇을 가리키는지 보여야 합니다.
2. **설명하다 만 문장을 남기지 않습니다.** 물음을 던졌으면 답하고, 근거를 들었으면 결론까지 잇습니다.
3. **한 문장 안에서 주어가 바뀌지 않게 합니다.**
   - "하늘이 열려 환상을 보고, 베드로가 입을 열어 깨달음을 말하며, 옥문이 열려 밖으로 나옵니다." → 보는 이와 나오는 이를 밝혀 문장을 나눕니다.
4. **주어를 밝힙니다.** 칸 첫 문장일수록 그렇습니다.
   - "바울의 마지막 편지로 봅니다." → "디모데후서는 바울의 마지막 편지입니다."
5. **서술어 없이 낱말만 두고 끝내지 않습니다.**
   - "우물가의 만남(29:2–12)." → "29:2–12에서 야곱은 우물가에서 라헬을 만납니다."
6. **줄표(—)와 가운뎃점(·)으로 문장을 압축하지 않습니다.**
   - "개구리·이·파리" → "개구리와 이와 파리"
   - 3장 6번의 지면 장치는 예외입니다.
7. **본문이 말하지 않은 일반화와 판정하는 부사를 쓰지 않습니다.** "늘", "어리석게도" 같은 말은 본문 근거가 있을 때만 씁니다.
8. **본문이 밝히지 않은 동기와 감정을 사실처럼 쓰지 않습니다.** "아마", "~했을 것입니다", "느꼈을" 같은 말로 채우지 않습니다.
9. **번역투는 같은 칸에서 세 번째부터 고칩니다.** '~을 통해', '~에 대해', '~라는 점', '가지다'가 여기에 들어갑니다.
10. **AI 말투를 고칩니다.** "~인 셈입니다", "~해도 괜찮습니다" 같은 안심 문구, 앞말 없이 던지는 경구("믿음은 결과가 아니라 걸음입니다")가 여기에 들어갑니다.

## 8. 칸마다 기준

한 날은 이 차례로 흐릅니다. ① 오늘의 흐름 → ② 성경 읽기(읽으며 표시) → 마음에 남은 말씀(독자가 씀) → ③ 눈여겨볼 것 → ④ 나의 묵상(본문 관찰, 하나님의 성품, 적용, 오늘의 기도) → ⑤ 쓴 뒤에 읽기(해설과 성경 전체로).

| 칸 | 기준 |
|---|---|
| ① 오늘의 흐름 | 장마다 요약을 늘어놓지 않습니다. 무엇이 문제인지(상황)를 먼저 놓고 흐름을 잇습니다. |
| 말뜻 | 사전 뜻만으로 끝내지 않고 읽는 방향을 줍니다. 예: "자백하다 — 죄를 죄라고 인정하여 그대로 말하는 것(1:9). 하나님이 죄라 하시는 것을 나도 같은 말로 인정하는 것입니다." |
| ② 성경 읽기(표시) | 물음 하나에 할 일 하나입니다. 물음과 할 일이 같은 곳을 가리켜야 합니다. |
| ③ 눈여겨볼 것 | 두 문장입니다. 본문에 무엇이 있는지 → 그래서 무엇이 보이는지. |
| ④ 본문 관찰 | 대표 흐름을 따라 한 물음입니다. 사실은 끊어 쓰고, 물음은 따로 씁니다. 찾아 적는 데서 끝나지 않고 "왜 …했다고 생각합니까?"처럼 이유를 생각하게 합니다. |
| ④ 하나님의 성품 | 근거 구절 → "하나님은 ~분이십니다." → 그 하나님 앞의 내 모습을 묻는 굵은 물음. 다짐과 실천은 적용에서 다루므로 여기서는 지금의 내 모습까지만 묻습니다. "내게는 어떻게 다가옵니까"는 쓰지 않습니다. |
| ④ 적용 | "앞에서 떠올린 …"으로 성품 칸을 이어받습니다. 앞 문장은 하나님이 하신 일이고, 굵은 물음은 거기서 바로 나옵니다. 둘째 물음(→)은 할 일을 묻습니다. "하나님은 나를 어떤 마음으로 보실까요?"처럼 짐작을 묻지 않습니다. |
| ④ 오늘의 기도 | 4장 기도 규칙을 따릅니다. 적용과 같은 줄기여야 합니다. |
| ⑤ 해설 | 목사님 말투로 씁니다. 한 가지 풀이를 내놓고, "하나님은 ~분입니다."로 맺습니다. |
| ⑤ 성경 전체로 | 맨 앞의 도구 이름표(흐름, 약속, 주제, 모형, 인용, 반향 등)는 그대로 둡니다. 다른 성경 책과 이어지는 곳을 양쪽 장절과 함께 씁니다. |
| 다시 읽을 곳, 장면 나눔, 소제목 | 짧은 이름표입니다. 줄표로 압축하지 않고 자연스러운 말로 씁니다. |

**하루 한 줄기:** 한 날의 대표 관찰이 본문 관찰 → 하나님의 성품 → 적용 → 기도 → 해설로 이어져야 합니다. 한 칸만 엉뚱한 곳으로 가면 알려 주십시오. 예: "적용은 '피할 길'인데 기도는 '양보'를 구합니다." 이것은 고치지 말고 판정을 '흐름'으로 적어 의견만 줍니다.

## 9. 표기 통일

- 원고 문장은 현행 맞춤법을 따르고, 인용은 개역개정 그대로 둡니다. 예: "값없이"(원고) / "값 없이"(인용).
- "화목 제물", "어린 양"은 개역개정처럼 띄어 씁니다.
- 장절: 같은 장 안은 쉼표(17:9, 15), 다른 장은 세미콜론(13:1; 17:26), 범위는 붙임표(12:1–2)로 씁니다. 다른 책을 인용했다가 돌아올 때는 책 약칭을 다시 붙입니다.
- 물음표와 장절은 "무엇입니까(25:8)?" 꼴로 씁니다.
- 한 장짜리 책은 "요이 7절", "몬 18절"처럼 씁니다.
- 지명 뒤 산·강은 원고 문장에서 붙여 씁니다(시내산). 인용은 개역개정대로 둡니다.
- '하나 됨', '알려 주다'는 띄어 씁니다. '내디딜'(○)이고 '내딛을'(✕)입니다.
- 숫자: 인용과 성경 속 수는 한글로, 장절·연도·날 수는 아라비아 숫자로 씁니다.

## 11. 마지막으로

- 성도가 처음 읽고 걸리는 문장을 찾는 것이 가장 중요합니다. 맞춤법보다 "이 문장이 무슨 말인지 바로 보이는가"를 먼저 봐 주십시오.
- 고치는 사람의 문체로 바꾸지 마십시오. 원문의 말투와 길이를 살리고, 걸리는 곳만 고칩니다.
- 판단이 서지 않으면 고치지 말고 '확인 필요'로 남겨 주십시오. 목사님이 정하십니다.
