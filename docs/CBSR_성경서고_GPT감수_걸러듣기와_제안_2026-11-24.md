## 1. GPT가 옳아서 바로 고친 것 (source 7e7963b)

코드에서 하나씩 확인한 뒤 고쳤습니다.

| GPT가 짚은 것 | 확인 | 고친 꼴 |
|---|---|---|
| 적어 둔 글을 다 지우고 돌아오면 지운 글이 되살아남 | 맞음. 빈칸은 저장하지 않게 되어 있었음 | 비운 것도 저장. 기기 사이에도 지운 것이 전해짐 |
| 쓰다가 다른 앱으로 넘어가면 적던 글이 저장되지 않음 | 맞음 | 화면이 가려지거나 닫힐 때 저장 |
| Esc 한 번에 두 단계가 물러날 수 있음 | 맞음. 앱과 서고가 Esc를 각각 처리함 | 서고가 한 번만 처리. 글을 쓰는 중에는 자판만 내려감 |
| 키보드의 Tab으로 초점이 서고 뒤에 가려진 앱으로 나감 | 맞음 | 초점이 서고 안에서만 돎. 닫으면 서고 단추로 돌아감 |
| 느린 연결에서 떠난 서가가 다시 열릴 수 있음 | 코드상 맞음 | 원고가 늦게 와도 그 자리에 있을 때만 엶 |
| 시편이 '150장'으로 나옴 | 맞음 | '150편' |
| 통독표 안내 "그날 본문으로 갑니다"와 실제 움직임이 다름 | 맞음 | 말을 "날짜를 누르면 그날로 갑니다."로 고침(아래 2번의 ④) |
| "비워 두어도 됩니다"는 안심 문구 | 맞음. 앱의 '하지 않을 것'에 있음 | 뺌. "적고 싶은 줄만 눌러서 내 말로 적어 두십시오. 적은 줄에는 도장이 찍힙니다." |

시험: 고친 것 22가지(`test_fix.py`), 실제 빌드에서 Esc와 초점 5가지(`test_app4.py`), 앞선 시험 164가지 다시 통과.

GPT가 걱정했지만 문제가 아니었던 것: 닉네임을 정하지 않은 계정의 실명을 부르는지. 닉네임은 사용자가 '나' 탭에서 직접 적을 때만 생기므로 실명을 부르지 않습니다.

## 3. GPT에게서 받아 제안하는 것

### 출시 전 (작은 것)

| | 무엇 | 왜 |
|---|---|---|
| ① | **책 어디서나 '내 말로 적어 두기'로 가는 길.** 표지에 다섯 도장 줄을 작게 두거나, 아래 쪽 번호를 누르면 차례가 뜨게 | 지금은 로마서 열한 쪽을 다 넘겨야 나옴. 적어 둔 글을 다시 보려 해도 같은 길. GPT의 가장 좋은 지적 |
| ② | **회색 단서를 표지의 저자 바로 아래에도.** 지금은 배경의 마지막 쪽에만 있음(10권) | "저자는 마태입니다"와 "유서 깊은 전통입니다"가 떨어져 있어 초신자는 잇지 못함 |
| ③ | **'시기'와 '수신자' 칸 훑기.** 창세기는 기록한 때("출애굽 뒤, 광야에서"), 사사기는 다루는 때("여호수아가 죽은 뒤부터 …")가 같은 칸에 있음. 욥기 수신자("고난 가운데 하나님께 묻는 사람들")는 오늘의 독자 안내에 가까움 | 같은 칸이 책마다 다른 것을 가리킴. 66권 목록을 만들어 작업대에서 보시게 함 |
| ④ | **오늘 읽는 책이 둘 이상인 날.** 지금 앱의 통독표로는 한 해에 세 날(삼상 · 삼하, 옵 · 욘, 요이 · 요삼 · 유) | 지금은 첫 책만 안내함. 사서가 두 책을 말하고 고르게 함 |
| ⑤ | **말씀 화면에서 휴대폰 뒤로 가기가 닫기와 같게** | 지금은 앱의 예전 동작 그대로라 뒤로 가기가 닫기와 다름 |
| ⑥ | **실제 기기에서 한 바퀴.** 들어감 → 책 → 긴 쪽 → 적기 → 책에서 다시 보기 → 돌아옴 → 서가 → 닫기. 안드로이드, 아이폰, 태블릿 세로·가로 | GPT의 1순위이고 제 1순위이기도 함. 목사님 손이 필요함 |

### 출시 뒤

| | 무엇 |
|---|---|
| ⑦ | **독서대.** 마지막으로 펼친 책 한 권, 내가 적은 설명, 받은 통독표와 말씀 카드를 놓는 자리. '내 책상'과 '이어 보기'를 하나로 묶자는 GPT 제안이 좋습니다 |
| ⑧ | 오늘 읽는 책의 책등에 책갈피 |
| ⑨ | 참고 문헌을 들일 때 책마다 시대 · 성격 · 읽는 까닭 · 성경과의 관계를 붙임 |
| ⑩ | 사서의 말을 한곳에 모으기. 조건에 따라 달라지는 말은 필요해질 때 |
| ⑪ | 시범 사용자에게 한 권을 본 뒤 자기 말로 설명해 보게 하기. 적는 칸을 채운 것과 책을 이해한 것은 다르다는 GPT의 지적 |

### 도장의 뜻 (원칙에 한 줄)

GPT 말대로 도장은 "이 줄에 내가 적은 글이 있다"는 표입니다. 이해했다는 증명이 아닙니다. '완료', '수료' 같은 말을 붙이지 않습니다. 서고에 들어온 것, 개론을 본 것, 내 말로 적은 것, 통독한 것은 따로 셉니다.

## 4. 설정에 대한 제안

목사님 방향(불, 66권을 먼저 구함)을 살리고, GPT의 말에서 쓸 만한 것 셋만 얹었습니다. GPT의 글에 목사님이 외경 · 위경 · 교부 문헌을 "시대를 잇는 가교"로 덧붙이셨다고 되어 있어 그렇게 읽었습니다.

- 오래전 이 서고에 불이 났습니다. 사서는 66권을 먼저 옮겼습니다. **성경이라서 먼저 구했습니다.**
- 맨 끝의 책들은 그날 건지지 못했고, 사서가 한 권씩 다시 들여놓는 중입니다. 그래서 지금은 "아직 들여놓은 책이 없는 것 같다."입니다. 목사님이 여유 있을 때 책을 넣으신다는 계획과 그대로 맞습니다.
- 그 책들은 성경이 아닙니다. 성경 시대와 그 뒤의 교회를 잇는 다리로 읽습니다. 사서가 막아서는 것은 금서라서가 아니라 성경과 섞어 읽지 않게 한 번 묻는 것입니다.
- 탄 열쇠는 끝 서가의 열쇠입니다.

GPT에게서 받은 셋

1. 불은 건물에 난 일로 둡니다. "그 책들을 읽어서 불이 났다" 같은 까닭은 붙이지 않습니다.
2. "언젠가 말씀드리겠습니다"를 거듭하지 않습니다. 준비되지 않은 이야기를 예고하지 않습니다.
3. 사연은 말이 아니라 물건을 다루는 몸짓으로 보입니다. 탄 열쇠를 잠깐 내려다보고 길을 내주는 정도.
