# 성경 서고 — GPT UX/UI 검토 반영 (2026-11-26)

GPT에게 서고 화면 사진 64장(휴대폰·태블릿)과 지시문을 주어 받은 검토 14가지를 걸러 반영했습니다.

## 반영한 것 (12가지)

| GPT 번호(사진) | 고친 것 |
|---|---|
| 11 태블릿 책등 가림 | 짧은 화면(태블릿)의 서가에서는 사서의 말상자를 얼굴 없이 낮게 띄워, 아랫단 책 이름(에스라·느헤미야·에스더)을 가리지 않습니다. 말상자는 전처럼 4초쯤 뒤 사라집니다. |
| 28 통독표 글자 | 책 이름과 장 범위를 두 줄로 나누고 글자를 키웠습니다(어느 달이나 같은 틀). 안 읽은 날의 빗금을 옅게 했습니다. |
| 01–03 ▾ 단서 | 말상자의 ▾ 표시를 조금 키웠습니다. 글자 안내는 붙이지 않았습니다(아래 참고). |
| 20 적는 칸이 흐림 | 물음 글자를 밝게, 칸 바탕을 어둡게 하고, 비어 있는 줄 오른쪽에 '적기'를 붙였습니다. |
| 13·14 등 글 뒤의 그림 | 글이 시작하는 높이를 재어, 그 뒤는 늘 어둡게 가라앉도록 했습니다(쪽마다 높이가 달라도). |
| 12–26 아래 단추 | '앞 장 / 3 / 9 · 닫기 / 다음' → '이전 쪽 / 3 / 9쪽 / 다음 쪽'. 가운데는 단추가 아니라 쪽 표시만 합니다. 책에서 나가는 길은 위의 '‹ 서가'와 마지막 쪽의 '서가로'. |
| 04 안내 선택지 | '안내를 받아 이동한다' → '오늘 읽을 책으로 안내받는다' |
| 10·21 갈래 | 갈래 이름 아래 책 범위를 작게 적었습니다(예: 역사서 · 여호수아–에스더, 일반서신 · 히브리서–유다서). |
| 28 통독표 안내 | 달력 안에 "날짜를 누르면 서고를 나가 그날 읽기로 갑니다."를 늘 보이게 했습니다. 사서의 말은 "…날짜를 고르시면 그날 읽을 곳으로 보내 드리겠습니다."(긴 화면에서만). |
| 29 카드 간격 | 부채의 벌어짐을 13°에서 17°로 넓혀 카드마다 드러나는 면이 넓어졌습니다. |
| 14 ‹ 기호 | 서고를 나가는 단추만 '× 닫기'. 한 단계 돌아가는 단추는 '‹ 서고 / ‹ 구약 / ‹ 서가' 그대로. |
| 31 물건 | 누를 수 있는 물건에만 옅은 빛이 천천히 숨 쉬듯 돕니다. 글자 안내는 붙이지 않았습니다. |
