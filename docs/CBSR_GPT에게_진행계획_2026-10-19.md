## 1. 확정된 결정

### 일곱 관찰 도구 (화면 명칭)
장면 · 인물 · 화자 · 전환 · 반복 · 공백 · **아이러니**

| 도구 | 한 줄 풀이(화면) |
|---|---|
| 장면 | 언제, 어디서, 누가 모였는가 |
| 인물 | 누가 무엇을 원하고, 하나님은 무엇을 하시는가 |
| 화자 | 누가 하는 말인가, 그 말은 믿을 만한가 |
| 전환 | 이야기는 어디서 꺾이는가 |
| 반복 | 되풀이되는 말과 장면은 무엇인가 |
| 공백 | 본문이 말하지 않은 것은 무엇인가 |
| 아이러니 | 독자는 알고 인물은 모르는 것은 무엇인가 |

- 보고서의 '관점'안은 채택하지 않는다. 성도 화면에 '화자'와 '관점'이 나란히 있으면 둘의 차이를 설명해야 하는 부담이 더 크다. '반어'는 '아이러니'로 부르고, 위 풀이처럼 극적 아이러니로 좁게 정의한다.
- '흐름'안은 채택하지 않는다. '전환'은 찾을 지점이 구체적이다. 질문에서는 갈등이 생기고 풀리는 과정까지 함께 묻는다.

### QT 네 단계
**본문 관찰 → 하나님의 성품 → 그리스도에게로 → 적용** (앱 반영 완료, 6c210b6)
- '더 깊이 관찰하기'는 본문 관찰 단계 바로 아래로 옮겼다.
- 기존 입력 칸·도장·기록은 그대로다.

### 365 통독표
- 올해(2026) 판은 장 나누기와 소제목을 바꾸지 않는다. 명백한 오타 3건만 고쳤다(브살렐이, 띄어쓰기, 끝 쉼표).
- 분절 7쌍과 소제목 46건은 「CBSR_2027_365통독_개정후보」로 보관했다. 겔 33–36 / 37–39안은 제외했다(36:26 '새 영'과 37장 '생기'가 한 짝).

## 2. 보고서에서 받아들인 것
- **도구 기록의 의미:** 클릭 수는 쓰지 않는다. '관찰 기록'은 도구마다 그 도구로 QT를 마친 날을 센다(그날 질문의 도구 + 더 깊이에 글을 남긴 도구). 점수·순위·배지로 만들지 않는다.
- **기계적 대응 경계:** 질문과 살펴보기의 도구는 질문이 요구하는 관찰 행위 기준으로 분류한다. 단서 종류 → 도구 대응은 기본값일 뿐 검수 대상이다.
- **사람 검수:** 365 통독표 분량은 목사님 검수 후 확정한다. 리딩지저스는 2027년에 빠지므로 자동 분류만 한다.
- **장르:** 시편 화자를 이야기의 서술자와 같게 다루지 않는다. 자동 화자 판별은 대화 구분 자료가 있는 곳에서만 작동한다.
- **2027 개정 시 주의:** 장을 옮기면 그날의 요약·퀴즈·QT·성품·읽는 눈·되풀이되는 말·주차 제목을 함께 다시 맞추고, 기존 기록은 판(버전)으로 구분한다.

## 3. 받아들이지 않은 것
- "이름 먼저 바꾸면 불일치": 장 경계를 바꾸지 않으므로 해당 없다.
- primaryLens / secondaryLens / evidenceRef / genre / reviewStatus 다섯 칸 구조: 규모에 비해 과하다. 근거 절은 이미 살펴보기마다 있다. 도구(1~2개)와 검수 상태만 둔다.

## 4. 진행 순서
1. **완료:** 말하는 이 판별(0931843), QT 네 단계 이름(6c210b6)
2. **진행 중:** 읽는 눈 질문 635개(365일 + 리딩지저스 270일)와 살펴보기 단추에 도구 1~2개 분류 → 365분 검수 목록 제출
3. 화면 표시: 오늘 카드와 QT 본문 관찰 줄에 이름표. 한 줄 풀이는 도구마다 처음 세 날만 보이고, 이름표를 누르면 다시 보인다. 단서와 더 깊이 렌즈 이름도 도구로 통일한다.
4. 나의 기록에 '관찰 기록' 추가
5. 365분 검수 결과 반영
