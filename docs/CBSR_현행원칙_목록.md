# 이야기통독(CBSR) 현행 원칙 목록

마지막으로 고친 날: 2026-11-23

새 작업을 시작할 때 먼저 읽는 한 장입니다. 목사님 결정을 모았고, 문서끼리 다르면 가장 나중에 정하신 것을 따릅니다. 3번 '공통 원칙'의 문장은 Claude가 그 결정들을 줄여 쓴 것이라, 목사님이 고치시면 고치신 문장이 원칙입니다. 자세한 내용은 `CBSR_GPT인계_저장소에_없는_원칙과_결정_2026-11-23.md`에 한 문서로 옮겨 두었습니다.

이 목록은 Claude 프로젝트 'CBSR'과 저장소 source 가지 docs 두 곳에 같은 내용으로 둡니다. 고칠 때는 두 곳을 함께 고칩니다.

## 1. 목적

> 이야기통독은 성경 본문을 관찰하고, 오늘 말씀하시는 하나님과 만나는 시간입니다. (목사님, 11-18)

- 누구를 위해: 초신자와 통독을 처음 하는 청년 성도
- 무엇을 돕나: 성경을 읽고, 이해하고, 기억하고, 통독을 이어 가는 일
- 무엇이 다른가: 내러티브 비평으로 읽는 통독과 묵상, 지도와 여정
- 정식 출시는 2027-01-01이고, 지금은 안정화가 먼저입니다(11-20).

## 2. 하루

① 오늘의 흐름 → ② 성경 읽기(읽으며 표시) → ③ 눈여겨볼 것 → ④ 나의 묵상(본문 관찰, 하나님의 성품, 적용, 오늘의 기도) → ⑤ 쓴 뒤에 읽기(해설과 기도)

앱으로 하든 가이드북으로 하든 같은 하루입니다(11-09).

## 3. 공통 원칙

1. **본문이 먼저입니다.** 도구와 해설은 본문을 따라옵니다. 인용은 개역개정 그대로 씁니다.
2. **하루 원고는 한 벌이고 한 줄기입니다.** 대표 관찰 하나가 스토리의 발견, 본문 관찰, 하나님의 성품, 적용, 기도, 해설로 이어집니다. 앱과 가이드북이 같은 원고를 읽습니다(11-09, 11-17).
3. **통독 안내는 범위 전체를, 묵상은 한 가지 발견을 맡습니다**(11-18).
4. **성도가 먼저 찾고 씁니다.** 해설과 기도는 쓴 뒤에 읽고, 해설은 한 가지 풀이로 내놓습니다. 하나님의 성품은 모든 본문에서 찾습니다(11-10, 11-19).
5. **안내는 첫날부터 끝까지 같은 꼴입니다**(11-12, 11-13).
6. **통독을 마치면 다음은 묵상입니다.** 통독 완료는 본문을 읽거나 들은 것으로 셉니다. 스토리와 도전은 통독 전에도 열려 있고 기록은 따로 셉니다. 내일부터의 날은 본문만 엽니다(11-02, 11-09, 11-13, 11-23).
7. **본문이 말한 것과 풀이와 추정을 가립니다.** 본문이 밝힌 것까지만 쓰고, 지도에서는 추정한 위치와 길을 표시합니다.
8. **쉬운 말로, 해야 할 것을 말합니다.** 해설은 목사님 말투로, 짧은 칸은 담백하게 씁니다(11-13, 11-20).
9. **자료를 지킵니다.** 사용자가 써 둔 기록과 목사님이 쓰신 문장은 그대로 둡니다(11-12, 11-13).
10. **돌아갈 곳은 들어갈 때 정합니다**(11-23, GPT 레이아웃 감수 뒤 목사님 동의).
    - 기본 탭(오늘·본문·묵상·도전·나)에는 뒤로 단추가 없습니다. 같은 탭을 다시 누르면 그 탭의 첫 화면 맨 위로 갑니다.
    - 하위 화면(성경 책장·내 노트·통독표·스토리 모음 등)의 ‹는 그 화면을 연 자리로 돌아갑니다. 보던 날짜, 고른 것, 스크롤 자리를 그대로 둡니다.
    - 전체 화면(스토리·지도 크게 보기·말씀 카드 편집·소그룹 진행)은 ✕나 마침으로 들어온 자리로 돌아갑니다. 묵상 탭에서 열린 스토리는 닫으면 묵상으로 갑니다.
    - 잠깐 뜨는 창(성구 확인·그림 고르기)은 닫으면 하던 자리와 초점으로 돌아갑니다. 창이 떠 있는 동안 뒤 화면은 눌리지 않습니다.
    - 메뉴에서 다른 화면을 열면 메뉴는 닫힙니다.
    - 휴대폰의 뒤로 가기는 화면의 ‹·✕와 같은 일을 합니다.
11. **머리줄은 한 틀입니다**(11-23, B안). 태블릿에서 모든 화면의 머리줄은 높이와 왼쪽 선(탭 줄 옆)이 같습니다. 기본 탭은 날짜가 주인이고 화면 이름은 그 위에 작게 둡니다. 하위 화면은 같은 자리에 ‹와 화면 이름을 두고 날짜는 두지 않습니다. 두 칸 화면은 머리줄 하나에 칸마다 자기 도구를 붙입니다.

## 4. 기능의 역할

| 기능 | 맡은 일 |
|---|---|
| 오늘 | 그날 그림과 줄거리, 지금 할 일 하나를 보여 줍니다. |
| 본문 | 성경을 읽고 듣는 자리입니다. ① 읽기 전 안내와 ③ 눈여겨볼 것이 여기 있고, 태블릿에서는 가이드북을 나란히 엽니다. |
| 묵상 | 탭을 누르면 그날 스토리가 먼저 뜨고, 다 보거나 닫으면 묵상입니다. 마지막 카드의 '오늘 다시 안 보기'를 고른 날은 바로 묵상입니다. ④ 네 단계를 한 장씩 쓰고 ⑤ 해설과 기도를 읽습니다. 물음, 해설, 기도 모두 가이드북 원고입니다. 화면은 물음(굵은 고딕)·말씀(노란 띠)·나의 글(공책 줄, 남색 펜) 세 층입니다(11-23). |
| 스토리 | 그날의 한 가지 발견을 전체 화면 카드로 넘겨 봅니다. 9장이 기준이고 ±2장입니다. 생각거리의 물음은 적용 물음과 같습니다. |
| 지도·여정 | 본문에서 열면 그날의 길을 보여 주고 읽던 곳으로 돌아옵니다. 찾아보기에서는 지도가 성경으로 들어가는 입구입니다. 여정 세션이 전담합니다. |
| 가이드북 | 같은 하루를 종이와 성경책으로 합니다. 책 단위 다섯 권, A5 펼침면입니다. |
| 도전 | 읽은 말씀을 본문에서 다시 찾아봅니다(본문에서 찾기, 퀴즈, 빈칸, 꼭 외울 말씀 100). |
| 주일 공과 | 주일에 교육부서 공과 본문을 같은 다섯 걸음으로 합니다. 기록은 통독과 따로 셉니다(11-22). |
| 소그룹 인도 | 모임 전 준비, 일곱 순서, 기록입니다. 물음과 적용과 기도는 가이드북 원고를 씁니다(11-20). |
| 나 | 읽은 날, 묵상 노트, 형광펜, 말씀 카드를 모아 봅니다. |

## 7. 원칙과 아직 다른 곳

- 앱: 묵상 탭 '쓴 뒤에 읽기'가 아직 스토리 원고의 해설·기도를 씁니다.
- 앱: 완료창 '최근 4주' 달력이 월–토입니다. 옛 도움말과 '스토리 QT' 문구가 남아 있습니다.
- 원고: 4일과 5일 스토리의 범위가 통독표와 다릅니다(10–13장 / 14–16장).
- 작업대: 스토리 요청문이 '9–12장'입니다.
- 지도: 지구 지도에 지명의 추정 여부가 넘어가지 않습니다(여정 세션).

## 8. 열려 있는 결정

- 지도를 볼 때 탭 줄을 아예 감출지, 통독표를 열면 '나' 탭이 켜지게 할지 — 성경 책장 재디자인(다른 세션) 뒤에 정함(11-23).
- 소그룹 기록의 보관 기간과 인도자가 바뀔 때의 인계
- `CBSR_GPT2차검토_반영과_결정할것_2026-11-20`의 '목사님이 정할 것'(개인정보 안내, 계정·기록 삭제 방법, 만 14세 미만, 성경 본문 사용 허락, 그림 권리 장부 등)

## 9. 원칙을 더하거나 바꿀 때

1. 어느 층인지 먼저 정합니다. 매체가 바뀌어도 남으면 원고, 매체와 함께 바뀌면 전달입니다.
2. 이 목록의 해당 줄을 고치고, 물러난 줄은 6번으로 옮깁니다.
3. 앱이나 원고가 아직 따라오지 못했으면 7번에 적습니다.
