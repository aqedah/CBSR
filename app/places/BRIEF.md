# 성경 지명 설명 만들기 (교회 청년·초신자용 통독 앱)

통독 앱의 '단어 설명' 아래에 새로 생기는 **지명** 항목입니다. 본문에 나오는 땅 이름을 누르면 짧은 설명이 뜹니다.
맡은 책들을 처음부터 끝까지 읽으며, 나오는 **장소 이름**(나라·지역·성읍·마을·산·강·바다·광야·골짜기·우물·망대·성문·연못·제단 이름 등)을 모두 뽑아 설명을 씁니다. 사람 이름은 넣지 않습니다.

## 도구
- 본문 읽기: `python3 /home/claude/rj/tools/readbook.py 책번호 [시작장 끝장]`
- 낱말이 어디 나오는지(조사 붙은 것 포함, 다른 낱말 속에 들어간 것은 제외): `python3 /home/claude/rj/tools/findword.py 낱말 [책번호…]`

## 항목마다 쓰는 것
- "d" 설명: 1~2문장(30~110자). 어디쯤 있는 어떤 곳인지 + 성경에서 기억할 일 하나. 쉬운 말, '~입니다' 체.
  예) "므깃도": "이스르엘 평야를 지키던 요새 성읍입니다. 큰 싸움이 자주 벌어진 곳으로, 요시야 왕이 이곳에서 전사했습니다(왕하 23:29)."
  위치가 확실하지 않으면 "정확한 위치는 알려져 있지 않습니다"라고 솔직히 씁니다. 추측을 사실처럼 쓰지 않습니다.
- "k" 종류: 나라 / 지역 / 성읍 / 산 / 강·바다 / 광야 / 골짜기 / 건물·성문 / 기타 중 하나.
- "m" (있을 때만) 이름의 뜻: 본문이 직접 풀이하거나(예: 브엘세바 창 21:31) 널리 알려진 뜻만, 한 문장. 확실하지 않으면 빼세요.
- "b" 이 이름이 장소로 나오는 책 번호 목록(맡은 책 안에서). findword로 확인.
- "r" 대표로 보여 줄 구절 [책,장,절] 하나 (그 장소가 실제로 나오는 절).

## 꼭 지킬 것
- 이름 표기는 개역개정 본문 그대로(예: 애굽, 바벨론, 앗수르, 갈멜 산이 아니라 본문에 '갈멜'만 있으면 '갈멜').
- **헷갈리는 이름은 "x":true 표시**: 같은 글자가 보통 낱말이거나(예: '아이'=성읍 이름이지만 '어린아이'의 아이와 같음, '라마', '소', '돌') 사람 이름으로도 쓰이면(예: '림몬'은 사람 이름이기도 함, '에돔'은 에서의 다른 이름) "x":true 를 넣고, "b"에는 그 책에서 장소로 쓰인 경우만 넣으세요. 앱은 이런 이름을 그 책에서만 짚습니다.
- 한 글자 이름은 넣지 마세요.
- '~ 산', '~ 골짜기', '~ 망대'처럼 띄어 쓴 이름은 본문 표기 그대로 띄어 쓴 형태로 넣으세요(예: "하나넬 망대", "감람 산"). findword로 실제 표기를 확인하세요.
- 설명에 장:절을 쓸 때는 실제로 확인한 것만.
