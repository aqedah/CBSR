## 11-20 통독 작업대로 옮김
- 목사님 결정: 새 틀을 통독 작업대(`app/site_src/guide.html`)의 기본으로. 원고는 `guide_qt.json`의 각 날 `v27` 칸(scenes · marks · looks · god)과 옛 칸(흐름 · 말뜻 · 관찰 · 적용 · 해설 · 기도 · 지도 · 그림 · 성경 전체로)을 함께 씁니다.
- `v27`가 있는 날은 작업대·인쇄·앱 태블릿 책 모양이 모두 새 틀로 그려지고, 앱 묵상 탭의 성품 물음과 ① 읽기 전 표시도 같은 원고를 씁니다.
- 표시 낱말은 `{동그라미}` `{형광펜}` `{물결 밑줄}` `{빗금 형광펜}` `{네모}` `{괄호}` `{번호 1 2 3}`으로 적습니다.
- 여기서 주 단위로 쓴 원고는 `python3 to_guide_qt.py`로 작업대 원고에 옮깁니다. 작업대에서 바로 써도 됩니다(날 머리의 "새 틀로 쓰기").
